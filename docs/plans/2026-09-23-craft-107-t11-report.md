## 做了什么（纵向切片：用户可观察行为）

成员打开一个已交付的不可变网页作品版本时，服务端从**记录在案的证据**推导该版本是否包含受限来源贡献；若包含，所有者在共享派生结果前看到**精确的 Version ID + 证据摘要**，必须做出明确决定。共享授权只在"活的、绑定当前版本+当前证据摘要的 owner 批准"存在时成立；拒绝、过期、重放（对其他证据的旧决定）、撤销以及非当前 owner 的任何提交都不产生授权；共享派生输出不授予任何原始来源访问，且决定/撤销/拒绝全部审计。

### 模块层 `internal/modules/craft/share.go`（纯规则，消费 T00 冻结 DTO）

- `RestrictedContributionFrom(versionID, manifest, record)`：受限判定完全来自记录证据——Run 的 T05 不可变知识记录中存在**跨租户来源**（组织共享库原始知识，`Source.TenantID ≠ Task 租户`）即 restricted；证据摘要 = 该版本 `citations.json` 清单的 `WebCitationsDigest`。引用清单只供摘要；**未引用但被 Run 消费的共享库来源同样判受限**（"contributed"语义，保守闭门）。
- `DecisionBinds(decision, contribution)`：同意绑定不可变 Version ID + 证据摘要；任一漂移即解绑。
- `RecordedShareDecision{Decision, DecidedAt, RevokedAt}` + `Validate`：持久事实的形状与生命周期校验（撤销不得早于决定）。
- `GrantsShareAuthority(contribution, decision, now)`：唯一授权规则——approved + 精确绑定 + `DecidedAt` 起算 `ShareDecisionTTL`（24h，模块常量）内未过期 + 未撤销。
- `ShareStateOf`：外部可见状态 `private | consented | declined`；非受限版本默认无同意要求（authority by default）。

### 服务层 `internal/application/service/craft_share.go`

- 端口：`DB`、`Versions`（`craft.VersionStore.Get` 读不可变版本）、`Files`（`GetFile(ref)` 读 `citations.json` 字节）、`Records`（复用 T06 的 `CraftCitationRecordReader`，同一 T05 存储）、`TaskAccess`（T08 checker）、`Now`（可注入时钟）。任一端口缺失拒绝构造（fail-closed，有专项测试）。
- `contribution()`：读版本 `citations.json`（缺失=空清单）+ 该版本 RunID 的已发布知识记录，复刻 citationRecord 同款 scope/run/发布态绑定检查（T06 文件不属本 lane 所有权，故自持 10 行同规则副本并注释来源）。
- `ShareView`（TaskRead，成员可读）：类型化同意摘要，永不含来源 ref/摘要文本/标题。
- `DecideShare`（每次提交新鲜 `TaskShare` 校验=仅当前 owner；viewer/collaborator/被撤销 owner 均拒）：决定只绑定**服务端当下推导**的贡献；请求携带 owner 所见的 `evidence_digest` 做 CAS，不匹配 → `ErrConflict`（同时覆盖"证据变化后重放旧决定"）。每 (tenant, session, version) 一行 upsert，新决定取代旧决定。
- `RevokeShare`（owner）：`revoked_at` 落库，行永久死亡；幂等。
- `ShareAuthority`（T13/T20 消费的门）：每次重新从记录证据推导 + `GrantsShareAuthority`；非受限直接放行。返回只有类型化贡献 + 布尔。
- 审计（`audit_logs`，复用 T08 行结构）：`craft.share_decision_recorded`（success）、`craft.share_revoked`（success）、`craft.share_denied`（denied，非 owner 试图决定/撤销）。审计写失败只记日志，不翻转已定的授权。
- SQL 全参数绑定（GORM `?`）；无外部 URL；无凭据字面量（Mimosa 约束）。

### Handler 层 `internal/handler/session/craft_share.go`

- `RegisterCraftShareFeature(routes, api)`：经 T00 constrained feature registry 注册 `"share"` feature。
- 路由：`GET /:id/craft/versions/:version_id/share`；`POST /:session_id/craft/versions/:version_id/share/decision`（body `{decision, evidence_digest}`）；`POST /:session_id/craft/versions/:version_id/share/revocation`。
- 错误映射稳定不泄露原因（body 仅 `{"error":"Forbidden"}` 等）；wire 投影仅类型化同意字段。

### 前端 `packages/views/src/craft/share.tsx`

- `projectShareView(raw)`：wire → 类型化视图；畸形载荷**丢弃不修复**（未知 status/非布尔 restricted/空 version 或 digest → null）；**陈旧决定不投影为授权**（decision 的 version/digest 与当前不一致即丢弃，`consented` 无绑定 approved 决定则降级 `private`——镜像服务端 `DecisionBinds`）。
- `CraftSharePanel`：owner 在 private+restricted 时见精确版本号、16 位截断证据摘要与 确认共享/拒绝共享 控件；consented 时见决定人+有效期与 撤回共享；非 owner 只读状态、零控件；面板永不渲染原始来源材料。样式沿用 lane 既有 `wk-craft-*` 纯类名模式（同 access.tsx/sources.tsx）。
