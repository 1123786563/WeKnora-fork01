### 设计（在计划所有权文件内，零迁移、零共享装配改动）

四检查晋升门 = 「候选 → 默认预览版本」的受守卫转换，沿既有不可变版本架构：

1. **域策略**（`internal/modules/craft/release.go` 追加，纯函数）：
   - 新检查名 `CheckPreviewReachable`（`preview_reachable`）与 `CheckPageLoad`（`page_load`），与既有 `CheckBuild`/`CheckEntry` 构成四项独立检查；消费 T00 冻结 DTO `WebCheckEvidence`（web_contracts.go:88，四项各 passed/failed/not_run）。
   - `WebPromotionRequest`：晋升回调绑定 Workspace/Run/Candidate/Revision，`Validate` 拒绝不完整回调。
   - `WebPromotionRecord`：证据记录绑定 Run + Workspace revision + 候选 Version 三元组；`Promotable()` 要求四项全部 passed（`Ready()`）——单项 failed/not_run 均不可晋升。
   - `WebChecks(record)`：渲染四项独立检查，每项 Detail 携带 `run <id>, workspace revision <n>, version <id>` 绑定串（持久化在 craft_versions.checks_json，纯函数渲染保证重放字节一致 → Publish 幂等收养）。
   - `WebEvidenceFromChecks(checks)`：从版本已记录检查推导四项结果；缺失=not_run；**legacy W02 "preview" 检查不映射 page_loaded**——可达性证据不能替代加载证据。
   - `SelectDefaultVersion(versions)`：默认预览版本选择策略——newest-first 中第一个四项全过者；不可晋升版本（legacy/失败/未观测）永不入座，旧默认保持。
   - `WebBuildOutcome`/`WebEntryOutcome`：T04 构建证据（BuildRan/BuildExitCode）与入口清单到四检查结果的投影，未观测=not_run 不臆造。
2. **晋升服务**（`internal/application/service/craft_artifacts.go` 追加）：
   - `WebPageLoadProbe` 接口：T14 探针缝（reachable/loaded 两项独立 `craft.CheckOutcome`）；nil 探针 → 两项 not_run → 门拒绝（fail-closed）。
   - `WithWebPromotion(drafts, probe)` 流式装配器：中央装配一行接线；缺 draft-head store → `ErrUnsupported` 拒绝（revision 栅栏不可验证时整体拒绝）。
   - `PromoteWebVersion(ctx, scope, req)`：候选加载（仓储 ACL：跨会话 ErrNotFound/跨用户 ErrForbidden）→ 请求-候选绑定校验（Workspace/Run 不符=ErrConflict）→ **revision 栅栏**（req.Revision ≠ 当前 DraftHead revision = ErrConflict 陈旧回调）→ 四检查证据组装（build/entry 来自候选采集证据，reachable/loaded 来自探针）→ 任一非 passed → `ErrConflict`（错误信息逐项列 build/entry/preview_reachable/page_loaded 结果，不发布任何版本，候选保留为草稿）→ 全过 → `VersionStore.Publish`（身份=VersionID(workspace,run,manifestDigest)，内容寻址 → 重复回调幂等收养同一行，不可能造重复版本）→ 返回带 `WebEvidence` 投影的版本（DTO 已支持 web_evidence 投影，craft.go:329）。
   - `SelectDefaultVersion(ctx, scope)`：List + 域策略 + 证据回填投影。
3. **探针事实通道**（`internal/application/repository/craft_preview_check.go` 追加 `UpdateWebProbeCheck`）：T14 发布后探针事实的持久化通道——一次调用只记录一个事实（另一事实/build/entry/清单不动=独立记录）；**page_load=passed 前置要求 preview_reachable=passed**（通道层拒绝替代）；已达 passed 的 load 存在时不可撤回 reachability；已记录事实不同状态重写=ErrConflict（事实不可变），相同重写=幂等 no-op（重复回调安全）；同版本读取 ACL。
4. **前端域规则**（新文件 `packages/domain/src/craft/web-promotion.ts`）：`webCheckEvidenceReady`（四项全过才 ready）与 `defaultPreviewVersion`（newest-first 取第一个 ready；不可 ready 版本永不占默认席）——Go `SelectDefaultVersion` 的镜像域规则，类型取自 `@weknora/contracts` 的 `CraftVersionView['web_evidence']`（T00 已冻结契约，无 contracts 改动）。
