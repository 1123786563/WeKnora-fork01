The focused regression checks both Stop and status denial (`craft_control_f17_f20_test.go:75-86`); the original assembly report records the production checker wiring and its test.
3. **Cross-Run delegation — closed.** Both paths load a found Task and require requested ID, exact persisted owner/tenant/Session scope, and exact `Fence.RunKey` before StopIntent, result lookup, abort or observation (`craft_control.go:227-232`, `:613-625`, `:869-881`). The service tests assert a foreign-Run Task produces `ErrForbidden`, no StopIntent or abort, and no status observation (`craft_control_f17_f20_test.go:88-126`). A missing Task retains the plan's Run-level accepted-stop/unavailable-delegation behavior; no Task result or executor operation is derived from it.
