## 做了什么

### 1. 引用清单模块契约（`internal/modules/craft/citation.go`，新文件）

- **事实/推断二分**：`WebCitationKind`（`fact`/`inference`）；`WebCitationEntry{Kind, CitationID, Claim}`（claim 上限 512 字节、条目上限 200）；推断条目**永不携带** citation id（`ValidateWebCitationManifest` 显式拒绝"inference 呈现为来源事实"）。
- **稳定引用 ID 绑定实际来源**：`ValidateWebCitationManifest(m, recorded)` 要求每个 fact 的 `kc_` id（`KnowledgeCitationID` 形状）**在该 Run 实际记录的来源集合中**——形状合法但未记录的伪造 id 也被拒；`recorded` 为 nil 时全部 fact fail-closed。
- **严格解码**：`DecodeWebCitationManifest` 拒绝未知字段/缺 entries 字段/非法形状（对齐 T04 `ParseCraftWebBuildLog` 先例）。
- **页面标记契约**：`ValidateWebCitationView(entryHTML, m)` 把渲染页与清单双向绑定——页面中每个 `data-craft-citation="…"` 必须是清单声明的 fact（未声明标记不能解析到任何记录来源）；清单每个 fact 必须渲染；每个推断条目必须带显式 `data-craft-inference` 标记；同一元素不得同时携带两种标记。
- **规范引用视图渲染器**：`RenderWebCitationView` 产出离线安全 HTML 片段（仅页内 fragment 锚点 `#craft-cite-…`、固定类名、`html.EscapeString` 转义 claim），构造上通过 T04 钉住工具链 denylist（无外部/绝对引用、无嵌入/脚本标签、无内联事件处理器、无 css fetch）；中英双语固定文案（`[事实来源]`/`[模型推断]`、`[Source fact]`/`[Model inference]`）。
- **不泄露占位符**：`WebCitationPlaceholder{CitationID, Kind, Status=unavailable}`——结构上只有稳定引用 id/类别/状态，无 ref/digest/title/excerpt 字段；`WebCitationOpen` 强制 ref 与占位符恰其一（`Validate`）。
- **证据摘要**：`WebCitationsDigest` 供 T07（版本钉住证据）/T11（受限贡献证据摘要）绑定。

### 2. 引用服务（`internal/application/service/craft_citations.go`，新文件）

- **端口**：`CraftCitationRecordReader`（生产适配 = T05 同一记录仓储，网页引用与工作台证据观察同一不可变事实）+ `CraftCitationSourceAuthorizer`（生产适配 = `*CraftKnowledgeService.AuthorizeSourceOpen`，即既有新鲜授权链）+ `craft.TaskAccessChecker`。`Records` 缺失即装配失败（fail-closed）。
- **`AdmitStagedWebCitations`（候选打包前准入闸）**：校验 staged 输出含 web 入口 `index.html`；`citations.json`（固定输出相对路径，随不可变产物一起入库并被文件清单 digest 钉住）存在时严格解码 + 绑定 Run 已发布记录的实际来源；页面标记与清单双向一致；**无 `citations.json` 时页面不得出现任何引用标记**（无清单的"事实"无法冒充被引）。服务端权威：记录 scope/RunID/发布态绑定检查（跨租户/跨任务 Forbidden、未发布 Conflict）。
- **`ResolveCitation`（引用打开）**：先过 Task 级 `TaskOpenSource`（任务级拒绝=权限错误而非占位符，且不触碰 ACL 缝）→ 引用 id 必须是该 Run 记录来源之一（伪造 id → `ErrNotFound`，绝不静默解析）→ 经新鲜授权缝取 ref；**来源级缺失/撤权/不可达 → 不泄露占位符**（ErrForbidden/ErrNotFound 归一为 placeholder，其余错误原样上抛）。
- **`WorkbenchAgreement`（网页/工作台一致性投影）**：对同一记录投影 fact 引用 id、记录来源 id、未绑定 id 三个列表（TaskRead + caller 身份检查），未绑定事实显式上报而非静默丢弃。

### 3. 生成页引用视图与工作台面板（`packages/views/src/craft/sources.tsx`）

- 新增 `CraftCitationFact`/`CraftCitationInference`/`CraftCitationEntry` 类型与可选 `citations` 属性（纯增量，无既有属性变更）。
- 渲染"引用与推断"块：fact 条目带 `data-craft-citation` 标记 + `[事实来源]` 标签，匹配的来源行标 `data-cited="true"` 并复用既有 `onOpenSource(citationId, ref)` 新鲜授权缝；推断条目带 `data-craft-inference="true"` 显式标记 + `[模型推断]` 标签，无打开控件；被撤权（`revokedCitationIds`）或无匹配来源行的 fact 渲染 `data-craft-citation-unavailable` 占位符（不显示 digest/获取时间/标题）。
