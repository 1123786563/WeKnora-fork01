## 做了什么（新增 `internal/container/craft_web_build_review.go` + 测试）

`CraftWebBuildCommandGate` —— T04 构建命令的审查入口，任何以固定离线 Web 构建名义派发的命令必须先过它。三层独立防线：

1. **固定形态门**：仅接受钉死形态 `python3 /opt/craft/web/build.py` + 已知 flag 集（`--toolchain/--input/--output/--runtime-digest/--selftest`，支持 `--flag=value`），且 `--toolchain` 值必须等于镜像路径 `/opt/craft/web`。借 T04 名义派发任意命令（换 script、未知 flag、wrapper 前缀、`bash`/`-c` 内联程序）→ `ErrForbidden` + 指明"仅接受钉死构建"的成员可见文案。
2. **宿主 EvalSymlinks 层（账本 :530 契约——服务端可解析的调用面在 screening 前解析链接）**：screening 前重载 `LoadCraftWebToolchainPin` 重验全部钉住字节（防构造→审查间 TOCTOU 漂移）；`filepath.EvalSymlinks` 解析工具链目录与 build.py，解析结果逃出工具链真身目录（symlink 外指）→ `ErrConflict`；`WithCraftWebHostInputsRoot` 指定宿主 staged inputs 树真身时，解析出的工具链根/构建程序与其重叠（工具链目录整体 symlink 指向材料树的部署攻击形态）→ `ErrConflict`。
3. **同一 T03 gate 复审**：`service.CraftExecutionPolicyGate.ReviewNormalExec`（与 `WithExecutionPolicy` 挂接两 exec 服务的是同一接口/实例语义）按持久 Run 身份参数绑定重载 admitted input manifest，做词法层 + 字节同一性 + stdin 身份全量审查；拒绝原样透传（`ErrForbidden` + "Allowed alternative" 成员可见 Refusal 文案）。
- **不静默**：全部拒绝路径 `logger.Warnf`（带 Run 身份与原因），gate 拒绝与通过均有入口级日志（通过日志含 toolchain digest）。
- **fail-closed**：gate 未装配（nil）时 Review 拒绝派发（构造允许、审查拒绝，测试钉住）；工具链目录不可达/漂移在**构造时**即拒（`ErrConflict`）。
