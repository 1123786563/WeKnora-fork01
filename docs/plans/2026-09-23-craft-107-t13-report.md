## 1. 做了什么（纵向完整切片）

用户可观察行为：**任务所有者在下载包含"派生自受限来源数据"的版本束之前，看到确切的文件与来源清单，并对不可变的导出清单摘要做出同意决定；无有效同意时下载只得到不含受限派生文件的安全回退包，任何受限派生字节都不返回。**

三层实现（全部为新增文件，零修改既有文件——所有权边界严格保持）：

| 层 | 文件 | 内容 |

| 模块 | `internal/modules/craft/export_consent.go` | 纯规则（T00 冻结 DTO 之上）：`ExportConsentState`（none/awaiting/consented/declined 闭词汇）；`DerivedFileRestricted`/`RestrictedDerivedPaths`——按**记录的 origins 逐文件**分类（任一 origin 受限 ⇒ 该派生文件受限；读 origins 事实而非文件自身的 Restricted 旗标——那是受限原件标记，按构造从不进入版本清单）；`SafeExportManifest`——安全回退投影（保留非受限派生成员、事实逐字不动、自派生新摘要，与全量摘要必不同；全受限情形诚实地退化为空但仍 Validate 通过）；`ExportDecisionBinds`（同 Version ID + 同 Export Manifest 摘要才绑定）；`GrantsExportAuthority`（approved + 绑定 + **当前** owner 三者齐备才授权——拒绝/陈旧重放/前任 owner/未知一律不授权）；`ExportConsentStateOf`（状态归约） |

关键设计裁决（依据 Spec L67-68/L41/L80 与 Issue 验收）：
- **同意绑定物**：Version ID + Export Manifest 摘要（T12 `BuildExportManifest` 的规范摘要，origins 计入身份）。版本不可变 ⇒ 同一版本摘要恒定；「manifest 变化使旧同意失效」由跨版本/跨摘要不绑定 + 决定行随 manifest_digest 存储共同保证（重放 v1 摘要对 v2 决定 = 409）。
- **无 TTL/无撤销端点**（与 T11 共享同意不同）：导出无外泄 URL 可流通，每次下载经新鲜 TaskRead + 摘要复验；新决定 upsert 即覆盖。未加额外行为，未扩大首发范围。
- **下载缝不动 T12 文件**：gate 以同接口装饰器姿态就位，T20 装配时把 `NewConsentGatedExportService(exportSvc, consentSvc)` 传给既有 `RegisterCraftExportFeature` 即收口；装配前 T12 裸服务继续直出（fail-open 风险见 §5 接线需求 1）。
- **受限派生的分类是保守全有或全无**（当前 T12 投影给每成员挂全部 evidence origins）：任一跨租户来源贡献 ⇒ 全部成员受限派生 ⇒ 安全包=仅三份固定文档。模块分类函数按 DTO 逐文件通用，未来 per-file origins 投影无需改动。
