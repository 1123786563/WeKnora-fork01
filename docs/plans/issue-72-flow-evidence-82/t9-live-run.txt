stack; historical greens (settle-evidence, r4-flow*) rode a long-lived lab stack

turn: hand-seeding the wallet via API would fabricate the very fact under test.
NOT a product defect either (the settle chain itself is green). Classification:
BLOCKED — harness-state dependency in the tagged test's wallet snapshot. Fix
belongs to the test (drive the application fulfiller or drop/seed the wallet
expectation explicitly) — outside this task's authority to change assertions.
