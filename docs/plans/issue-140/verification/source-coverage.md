## 3. 使用条件（当前真实口径）

1. **登录**：Career Office 仅接受服务端认证所得 User/Tenant 作用域；匿名访问一律 401（本轮实测 `/api/v1/career/open`、`/api/v1/workbench/executions` 均匿名 401）。
2. **request-id 幂等**：所有写入（提案/导入/评估/申请/材料/导出/投递/进展/搜索）携带请求编号；同 ID 重放返回同一回执、同 ID 改内容被拒；结果未知时用**原**请求编号对账或安全重发，不重复执行（本轮页面声明 + T04/T07/T08/T22 既有 HTTP 实证）。
3. **额度 admission**：找岗/规则触发等收费 Run 执行前预占额度并向用户展示预估（本轮 Web 找岗页呈现「本期剩余 50/50 · 已预占 0 · 已结算 0 · 计费窗口 2026-09-01 至 2026-10-01 UTC」与触发条件后端原文五条：预占幂等、终态结算、租约过期自动释放、UTC 自然月重置、额度耗尽只阻止新收费 Run 而**既有档案/申请/评估/搜索记录永远可读**、付费状态不改变岗位排序或资格判定）。
4. **越权边界**：跨租户读他人岗位/申请/材料/进展被拒（本轮 403/404 实测，evidence/web-cross-tenant-probes.txt）。
