## 一、做了什么（纵向切片）

用户可观察行为：**一个旧版本的证据永远指回它产出当时实际使用的来源事实（源 ref、内容摘要、采集时间、请求/包摘要），后续知识更新/删除/撤销不会改写旧版本的历史；而新 Run 的晋升必须能证明自己 Run 的证据，且打开引用来源始终按当前授权重新校验。**
