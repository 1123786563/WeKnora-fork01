### GREEN（实现）

1. **模块层 `internal/modules/craft/export_manifest.go`**（新增）
   - `BuildExportManifest(version, evidence, tenantID)`：T00 冻结 `ExportManifest` DTO 的推导函数——Files 恰为版本的不可变成员（`version.Files`），每个成员的 origins 为钉定证据（T07）的知识来源（`ExportOriginKnowledge`，跨租户来源 `Restricted=true`，按 ref/digest 排序）；成员自身恒 `Restricted=false`（受限原件按构造排除：原始知识字节从不进入版本 manifest）。
   - `ExportManifestDigest`：canonical 哈希——含 origins（T00 前向检查要求）、files 按 path 排序（顺序无关）、自引用 `ManifestDigest` 字段排除；不用 `ExportManifest.Validate()`（其要求 digest 已填，自引用矛盾），结构事实直接校验。
   - `BuildBundleCitationManifest` / `BuildBundleSources`：`sources.json` 投影——每个来源携带稳定引用身份（`kc_`+24hex）、digest、获取时间（三者逐字来自钉定证据）、尽力而为的显示 title（**不进 export manifest digest**：库行后续改名/删除不移动历史 bundle 指纹）、authenticated 引用（`craftkb://`，无 URL/凭据语义）。
   - `ValidateExportBundleMembers`：打包前防御校验（复用 `ValidateArtifactPath`：traversal/绝对路径/反斜杠/凭据形态一票否决 + digest 形状）。
   - 纯函数：输入全部为不可变事实（version + evidence），Workspace/当前知识库/live record 从不是输入 → 历史版本 digest 天然稳定。
   - 固定文档名常量：`export-manifest.json` / `sources.json` / `build.json`。

2. **服务层 `internal/application/service/craft_export.go`**（新增）
   - `CraftExportService.ExportBundle(ctx, scope, versionID)`：
     1. version id 形状校验（`ValidVersionID`）——traversal/畸形 id 与"缺失版本"同体 404（非泄漏，无任何查找）；
     2. 每次下载 `RequireTaskAccess(TaskRead)` 现查成员（owner/collaborator/viewer 可下载，story 21/23/31）+ caller 一致性双门（T10/T11 同款）；
     3. 只读不可变输入：`versions.Get`（仓储 scope ACL）+ `VersionEvidence`（钉定快照）；**无证据版本诚实 ErrNotFound，绝不从 Workspace/live record/当前知识库重建历史**（T07 同款失败封闭）；
     4. `ValidateExportBundleMembers` 防御（仓储行被毒化时整包拒绝）；
     5. 审计 `craft.export_bundle`（success：actor=member、TargetID=Version、details 含 manifest_digest/members/run_id）与 `craft.export_denied:{task_access,caller_identity}`（denied：T11 词汇表纪律 + `craftDenyDedupWindow` 滑动窗口去重）。
   - `CraftExportTitleSource` 端口（可选）：按 knowledge id 解析显示 title；失败/缺失诚实降级为空 title，绝不猜。

3. **HTTP 层 `internal/handler/session/artifact_download.go`**（追加，W26 既有内容零改动）
   - `RegisterCraftExportFeature`（T00 约束 registry，feature 名 `export`）+ `GET /:id/craft/versions/:version_id/export`（describe：digest/成员/引用清单/checks 投影，无原始材料）+ `GET .../export/download`（zip 流式打包：成员字节按 `version.Files[].Ref` 经 file reader 读取——绝不读 Workspace；三个固定文档内嵌）。
   - 错误映射复用 `craftShareHTTPError`（稳定非泄漏）；zip 条目名即已校验的 canonical 成员路径。
