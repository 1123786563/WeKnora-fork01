## Frozen downstream interfaces

**Go domain** (`craft`): `InputRecognition{Accepted, Understood bool; Reason string}`; `Input.Recognition *InputRecognition`; `CheckOutcome` constants `WebCheckPassed`, `WebCheckFailed`, `WebCheckNotRun`; `WebCheckEvidence{Build, Entry, PreviewReachable, PageLoaded CheckOutcome}` with `Validate()` and `Ready()`; `Version.WebEvidence *WebCheckEvidence`; `StopOutcome{RunID string; Status StopOutcomeStatus}` with `StopRequested|StopConfirmed|StopUnknown`; `WriterAcquireOutcome{WorkspaceID string; Status WriterAcquireStatus}` with `WriterAcquired|WriterConflict|WriterUnknown`; `BudgetPause{RunID, Reason string; Limit, Used int64}`; `RestrictedContribution{VersionID, EvidenceDigest string; Restricted bool}`; `ShareDecision{VersionID, EvidenceDigest, OwnerID string; Decision DecisionStatus}`; `ExportManifest{VersionID, ManifestDigest string; Files []ExportFile}` where `ExportFile{Path, SHA256 string; Restricted bool; Origins []ExportOriginRef}` and `ExportOriginRef{Kind ExportOriginKind; Ref, SHA256 string; Restricted bool}`. Origin kinds are `knowledge|input|artifact`; the opaque ref and digest describe provenance without granting access to the original. `ExportConsentView{Manifest ExportManifest; Decision *ExportDecision}` validates the decision's Version ID and Manifest digest against the manifest including origins. `ExportDecision{VersionID, ManifestDigest, OwnerID string; Decision DecisionStatus}`. Decision statuses are `approved|rejected|unknown`. All records expose `Validate() error`; invalid facts wrap `craft.ErrInvalidInput`. These are facts, not authority grants or durable transitions.

**Task access:** `craft.TaskAccessChecker.CheckTaskAccess(context.Context, craft.Scope, craft.TaskAction) error`; `craft.RequireTaskAccess(ctx, checker, scope, action) error`. Actions are `read|write|share|open_source|preview`. Missing checker or authenticated tenant/user/session returns `ErrForbidden`; invalid action returns `ErrInvalidInput`. T08 supplies the checker implementation, and T05/T14 consume it for current-scope authorization. `Scope.SessionID` is the Task ID.

**HTTP/registration:** `craftInputDTO` includes `recognition` only when `Input.Recognition != nil`; `craftVersionDTO` includes `web_evidence` only when `Version.WebEvidence != nil`. Existing DTO fields and error mapping are unchanged (`ErrInvalidInput` 400, `ErrForbidden` 403, `ErrNotFound` 404, `ErrConflict` 409, `ErrBusy` 409, `ErrUnsupported` 503). `session.RegisterCraftFeatureRoute(name string, mount func(session.CraftRouteGroup)) error` and `container.RegisterCraftFeature(name string, mount func(session.CraftRouteGroup)) error` freeze names before route mounting; duplicate, nil, and malformed names fail. Features receive a **constrained** view of the guarded session group, in alphabetical name order. GET paths must be canonical descendants of `/:id/craft/`; POST paths must be canonical descendants of `/:session_id/craft/`. Traversal, encoded escapes, backslashes, empty segments, absolute/sibling paths, and wrong method prefixes panic during construction before router or API-key policy registration. The feature handler/service must still enforce Task access. T20 invokes lane registrations before router construction.

**TypeScript wire:** `CraftInputView.recognition`, `CraftVersionView.web_evidence`, and `CraftRunView.budget_pause` are typed records or `null`; omitted legacy fields parse to `null`. When recognition is present, `reason` must be a string. `web_evidence` has `build`, `entry`, `preview_reachable`, `page_loaded`, each strictly `passed|failed|not_run`; `budget_pause` has `run_id`, `reason`, `limit`, `used`. `CraftExportFile.origins: CraftExportOriginRef[]` is required on new manifests. `CraftExportConsentView{manifest, decision}` preserves those origins and rejects a decision bound to a different version or manifest digest. Standalone public parsers cover stop/writer/budget/restricted contribution/share/export records and reject unknown enumerants or missing binding identities. The existing `CraftRunStatus` vocabulary remains unchanged; T19 may project `budget_pause` on a `waiting_user` Run without inventing a new terminal status. T00 does not yet emit it from Go.

**Web slots:** `createCraftWorkbenchFeatures(readonly CraftWorkbenchFeature[])` returns an immutable name-sorted list; each entry has `name`, `slot: 'header'|'conversation'|'aside'`, and `render({sessionId, canWrite, selectedVersionId})`. `CraftWorkbenchProps.features?` defaults to no features. Duplicate, malformed, or unavailable entries fail before render. T20 passes the assembled list; lanes own their component files.
