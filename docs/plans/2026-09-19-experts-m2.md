# Expert Templates (M2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate Octop's expert-templates capability into WeKnora: a builtin expert library under `config/experts/<id>/` (manifest + persona docs + optional skills), a scanner, an instantiate pipeline that creates a CustomAgent from an expert (i18n names, persona prompt, quick-prompts→starters, skill references with async install), an API, and a React experts page.

**Architecture:** Pure-logic package `internal/agent/experts` (manifest types + directory scanner) → `expert_service` composes the existing `customAgentService.CreateAgent` (no new agent-creation path) → skill references resolve against the tenant skill catalog, uninstalled ones packaged to zip and bridged into the existing async `InstallSkill` pipeline → gin routes `/api/v1/experts*` → React page at `/platform/experts`. No DB migration: expert provenance rides in `CustomAgentConfig` (JSON column), builtin experts are files only (market/publish tables are M4).

**Tech Stack:** Go 1.26 / gin / gorm (no migration) / yaml manifests / React 19 + packages/api-client + packages/ui.

**Spec:** `docs/superpowers/specs/2026-09-19-octop-capabilities-migration-design.md` §5 (Experts). Octop source of truth: `/Users/wuyongjun/trea/Octop/src/octop/infra/agents/experts/` (catalog.py, library/<id>/manifest.json).

## Global Constraints

- Builtin experts are DATA under `config/experts/` — no import-time disk IO; loading is explicit at startup alongside `LoadBuiltinAgentsConfig` (`internal/config/config.go:801`, configDir from `ConfigDir()` `internal/config/config.go:722`).
- `builtin_agents.yaml` mechanism stays untouched; experts are a higher-level template producing ordinary CustomAgents (never `IsBuiltin=true`).
- Instantiate MUST reuse `customAgentService.CreateAgent` (`internal/application/service/custom_agent.go:70`) — no parallel creation path. ID/name/desc/avatar/config flow through the same request shape (`CreateAgentRequest` handler `internal/handler/custom_agent.go:58`); `EnsureDefaults` + `QuestionSuggestions.Validate` still run (so starters must be fully-formed: Mode `curated`, Count = len(Items)).
- i18n resolution copies the builtin precedent `resolveI18n` (`internal/types/builtin_agent_config.go:199`): exact locale → language prefix → `en` → first key. `LocaleText` keys are exactly `zh`/`en`.
- Quick prompts map to `QuestionSuggestions.Starters.Items` (spec §5; `types/custom_agent.go:316`); expert `welcome_message` is NOT migrated (WeKnora has no welcome-message surface — recorded deviation).
- Skill references: values are skill NAMES (SKILL.md frontmatter name, `TenantSkillEntity.Name`). Uninstalled skill + request `sandbox_config_id` → package the expert's `skills/<slug>/` dir as a zip and call `InstallSkill(ctx, tenantID, configID, archive)` (async, returns install ID); uninstalled + no sandbox config → reference still written, slug listed in response `pending_skills`.
- Provenance: `CustomAgentConfig.ExpertSource struct{ExpertID, Source, Slug string}` (json `expert_source`, omitempty) — absent from `defaultAgentConfig` on the frontend ONLY if hydrate keeps unknown keys (verify agent-editor.ts:199 behavior; M1 precedent says add to defaults).
- Persona text: prompt_files concatenated in manifest order, joined `"\n\n---\n\n"`, becomes SystemPrompt (or is prepended to manifest `agent_config.system_prompt` when present).
- JSON field naming snake_case; gofmt/vet clean; frontend changes only in apps/web + packages/api-client + packages/i18n (+ scripts/parity backfill registration for any new i18n keys, REACT_SIDE_SOURCES precedent).
- Octop asset fidelity: persona md and SKILL.md files copied verbatim; manifest fields mapped per the T2 mapping table; `metadata.octop` frontmatter blocks are kept as-is (harmless extra keys).

- [ ] **Step 1: Write the import script** (Python, mirroring M1's importer style):

```python
#!/usr/bin/env python3
"""One-time importer: convert 4 pilot Octop experts (manifest.json + assets)
to WeKnora config/experts/ layout (manifest.yaml). Re-runnable; verbatim assets."""
import json, shutil, sys
from pathlib import Path

OCTOP_LIB = Path("/Users/wuyongjun/trea/Octop/src/octop/infra/agents/experts/library")
OUT = Path(__file__).resolve().parents[1] / "config" / "experts"
PILOTS = {
    "general-assistant": {"skip_skills": ["octop-assistant"]},  # Octop-product skill, meaningless in WeKnora
    "ops-engineer": {},
    "stock-assistant": {},
    "news-trend": {},
}
# manifest.json → manifest.yaml field mapping (see plan Global Constraints):
# id→id; label→label; description→description; icon_name→icon_name; color→color;
# prompt_files→prompt_files; quick_prompts[{title,description,prompt,color,icon_name}]→quick_prompts
# (all LocaleText passthrough zh/en); skills discovered from skills/ dirs minus skip_skills;
# persona_mbti omitted (no Octop equivalent); agent_config: fixed per-expert below.
AGENT_CONFIG = {
    "general-assistant": {"agent_mode": "smart-reasoning", "kb_selection_mode": "all"},
    "ops-engineer":      {"agent_mode": "smart-reasoning", "kb_selection_mode": "all", "web_search_enabled": True},
    "stock-assistant":   {"agent_mode": "smart-reasoning", "web_search_enabled": True},
    "news-trend":        {"agent_mode": "smart-reasoning", "web_search_enabled": True},
}

def to_yaml_obj(m, skills):
    return {
        "id": m["id"],
        "label": m["label"], "description": m["description"],
        "icon_name": m.get("icon_name", "sparkles"), "color": m.get("color", "#6366f1"),
        "prompt_files": m["prompt_files"],
        "quick_prompts": [
            {"title": q["title"], "description": q.get("description", {}),
             "prompt": q["prompt"], "color": q.get("color", ""), "icon_name": q.get("icon_name", "")}
            for q in m.get("quick_prompts", [])
        ],
        "skills": skills,
        "agent_config": AGENT_CONFIG[m["id"]],
    }

for slug, opts in PILOTS.items():
    src = OCTOP_LIB / slug
    m = json.loads((src / "manifest.json").read_text(encoding="utf-8"))
    dst = OUT / slug
    dst.mkdir(parents=True, exist_ok=True)
    for f in m["prompt_files"]:
        shutil.copyfile(src / f, dst / f)
    skills = []
    skdir = src / "skills"
    if skdir.is_dir():
        for d in sorted(skdir.iterdir()):
            if d.is_dir() and (d / "SKILL.md").exists() and d.name not in opts.get("skip_skills", []):
                shutil.copytree(d, dst / "skills" / d.name, dirs_exist_ok=True)
                skills.append(d.name)
    import yaml  # pyyaml
    (dst / "manifest.yaml").write_text(
        yaml.safe_dump(to_yaml_obj(m, skills), allow_unicode=True, sort_keys=False), encoding="utf-8")
    print(f"{slug}: {len(m['prompt_files'])} persona files, skills={skills}")
```
