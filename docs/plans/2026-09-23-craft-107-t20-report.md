### 1.7 T03 验收裁定：镜像层 noexec / 解释器拦截（对 t03-report.md:84 留档项的 T20 裁定）

事实（本轮实读）：
- inputs/knowledge 为 RO bind（`expectedCraftRunViewMounts`，craft_runview_container_provider.go:1047-1048）；宿主发布固定 0644 无执行位（`writeRunViewInputAtomic`，pin 测试 `TestCraftT03InputPublicationLeavesNoExecutableBits` 在册）；容器 `ReadonlyRootfs`+`NoNewPrivileges`+`no-new-privileges:true`（craft_runview_docker_engine.go:343）。
- Docker typed Mount API 的 bind 挂载**不承载 noexec 旗标**（引擎映射仅 Propagation/ReadOnlyForceRecursive，craft_runview_docker_engine.go:350-356）；上 noexec 需改走 HostConfig.Binds 字符串通道并连锁 pinned-profile inspect 校验——引擎层接口变更。

**裁定**：
1. inputs bind `noexec` **不采纳为当前防线**：(a) 其防护目标（execve 上传文件）已被 0644 无执行位+RO bind+ReadonlyRootfs 完全覆盖；(b) typed Mount API 不支持，改造面大；(c) 对真实残余向量（容器内解释器 `python3 /workspace/inputs/x.py` 以数据读文件执行）noexec **无效**。列为后续可选加固（引擎层演进到 Binds 通道时再评估）。
2. 容器内解释器读上传文件：Spec 非目标未要求进程级拦截；服务端可控命令面的拦截已由 T03 策略完成，且经本轮 §1.5 工厂接入生产构造路径；残余向量记录为**已知接受风险**，最终收敛依赖 T19 S3 路由启用后服务端命令面成为唯一执行通道（届时策略门旅程已在生产构造路径在册复验）。
3. 宿主 sandbox-root noexec：同 1 的 (c) 理由，不解决解释器向量；宿主侧防线维持 0644+目录 0755+`O_NOFOLLOW`+no-replace 原子发布。
