# T13 artifact preview follow-up — 2026-09-12

## Scope

The React Web chat artifact row now exposes a preview action for safe inline
preview kinds and retains a protected download action. Preview bytes are still
fetched through the authenticated session/message artifact route; no storage
URL, sandbox path, or provider location is copied into the shared model.

## Implemented behavior

- `artifactPreviewModel` classifies text, Markdown, image, and PDF artifacts
  for inline preview.
- HTML/XHTML, SVG, Office formats, and unknown types remain explicit
  `download-only`; the preview surface never executes uploaded HTML or SVG.
- Markdown preview reuses the shared escaped/allow-listed renderer. Image and
  PDF previews use object URLs that are revoked on cleanup; the PDF iframe is
  sandboxed without permissions.
- Preview requests are invalidated on chat-session changes and stale async
  responses cannot replace a newer preview.
- `d58b4a6` rejects SVG MIME values with parameters (for example,
  `image/svg+xml; charset=utf-8`) as download-only as well.
