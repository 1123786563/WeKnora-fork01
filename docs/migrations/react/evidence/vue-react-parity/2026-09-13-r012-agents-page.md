Parent review round 1 requested these exact labels.
4. Guide components — ContextualGuide/TenantModelsGuide/NewUserGuide flows are separate slices; the agents page renders data-guide="agent-list-create" anchors for them.
5. Space-view capability — org rail entries + GET /organizations/:id/shared-agents space view are wired; per-org badge counts use the shared-agents payload (Vue also merges GET /organizations resource_counts.agents.by_organization).
