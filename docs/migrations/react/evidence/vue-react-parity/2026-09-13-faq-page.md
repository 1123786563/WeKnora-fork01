## 剩余差距（不阻塞本切片验收）

1. 分页：Vue 为滚动无限加载；React 保留上一页/下一页分页器（既有功能保留）。
2. 编辑抽屉：React 用多行 textarea（每行一条）；Vue 为输入框+加号逐条添加/删除行。
3. 标签面板缺"管理标签…"底部链接（React 无对应页面锚点）；标签搜索框未做。
4. 知识库信息卡为简化版（类型/描述/创建时间）；Vue 含访问角色/共享/分块/统计等分区（部分 key 缺失，见上）。
5. 导入对话框缺解析预览（共解析 N 条记录）与"下载示例文件"下拉；导入进度条/结果徽标（faq-import-strip）未做，导入反馈用 Status 行。
6. 卡片级启用/推荐开关、批量栏的 Vue 样式对齐未做（React 保留批量操作条与编辑抽屉内开关）。
7. "检索测试"抽屉未实现；检索图标按钮按任务书映射为提交搜索（与搜索框 Enter 同义）。
8. Vue 悬浮 tooltip 为组件实现；React 用原生 title 属性近似。
