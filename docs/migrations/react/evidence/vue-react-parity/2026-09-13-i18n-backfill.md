## Pager copy (block 2 detail)

Per the slice spec, the values were taken **byte-identically** from the React panel's fallback table (apps/web/src/settings/TenantMembersPanel.tsx:49-52,79-82). Two key-name sets ship:

- `tenantMember.pager.{totalItems,itemsPerPage,jumpTo,pageUnit}` — slice-spec names (acceptance spot-check target).

ja-JP / ko-KR / ru-RU carry the en-US copy for these 8 keys, matching the panel's current en-US fallthrough byte-identically (no rendering change; real translations are a follow-up).
