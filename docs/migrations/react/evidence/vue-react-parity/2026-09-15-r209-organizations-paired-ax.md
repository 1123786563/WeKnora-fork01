# R209 组织页 React/Vue 配对 AX 验收（2026-09-15）

## 范围

在同一 Chrome 会话、zh-CN、1355x720 视口下，分别打开：

- React：`http://localhost:5181/platform/organizations`
- Vue：`http://localhost:5173/platform/organizations`

两端均使用空共享空间后端夹具，比较平台导航、共享空间范围切换、空状态文案与创建/加入入口。

## 观察结果

React AX 暴露：平台导航（新对话、知识库、智能体、共享空间）、共享空间范围链接（全部、我创建的、我加入的）、共享空间标题、加入/创建按钮及空状态文案。Vue 暴露相同的可见锚点与顺序；其范围项由 presentation container 承载，React 提供了额外的 button/link 语义和 `?scope=created` 目标。

React 与 Vue 的用户可见内容一致：

- 共享空间标题
- 全部 / 我创建的 / 我加入的
- 加入共享空间、创建共享空间
- “创建或加入共享空间，让多个空间互相协作，共享知识库与智能体”
- 空状态“您还没有加入任何共享空间”及辅助说明

## 结论

当前组织空状态没有发现需要继续修改的可见结构差异。React 的额外语义标注属于可访问性增强，不改变视觉和交互锚点。后续仍需真实共享空间/成员后端夹具、响应式、多语言、Wails/桌面与原生端证据，才能关闭对应矩阵条目。
