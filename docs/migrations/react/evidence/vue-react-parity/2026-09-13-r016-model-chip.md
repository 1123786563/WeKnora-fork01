# R016 · 新建对话视图模型 chip：真实模型名 + 上下文规格（Vue→React parity）

日期：2026-09-13　分支：codex/react-multiclient（worktree react-multiclient，未 commit）
缺陷（五语双端 live 截图取证）：新建对话视图的模型 chip，Vue 显示真实模型名 + 上下文规格（如 mock-stream-model 200K），React 只显示本地化占位文案（对话模型/チャットモデル）。

## 1. Vue 侧数据链（行号取证）

chip 模板：frontend/src/components/Input-field.vue:2784-2804（.model-display > .model-selector-trigger，name span + ctx span .model-selector-ctx（is-default 修饰）+ 下拉箭头）；下拉选项同样展示 ctx（:2818-2834）。creatChat.vue 仅内嵌 <InputField>（frontend/src/views/creatChat/creatChat.vue:46），chip 完全由 Input-field 驱动。

- 选中模型 id：selectedModelId ← settingsStore.conversationModels.selectedChatModelId（:706-709）。
  - 初始优先级：localStorage last pick > store 值 > 第一个可用模型（initChatModelSelection :953-966、ensureModelSelection :982-994）。
  - 智能体绑定：watch 把所选智能体 config.model_id 同步进选中（:1001-1024，用户刚手动选过则保留）。
- 模型对象：selectedModel = chatResources.chatModels.find(id)（:1067-1069）；chatModels = allModels.filter(m => m.type === 'KnowledgeQA')（frontend/src/stores/chatResources.ts:59，来源 GET /api/v1/models）。
- 显示名：display_name?.trim() || name（:1072-1084）；无模型/未选中 → t('input.notConfigured')（「未配置」）；共享智能体模型不在本空间列表 → input.sharedAgentModelLabel（:1075-1077）。
- 上下文规格：formatContextWindow(parameters?.context_window)（:1093-1096），缺省按 200K 后端默认（effectiveContextWindow，frontend/src/utils/contextWindow.ts:9-43：128000→128K、200000→200K、1048576→1M）；is-default = 未显式设置（:1098-1100）；title 提示「未设置，使用默认 {value} / {count} tokens」（:1086-1091）。
- 点击行为：chip 可点开模型选择下拉（toggleModelSelector，:2788）；isModelLockedByAgent 已恒为 false（:466-469）。
- i18n input.notConfigured：zh-CN 未配置 / en-US Not configured / ja-JP 未設定 / ko-KR 구성되지 않음 / ru-RU Не настроено（各 locales input 块）。

## 2. React 侧既有链路（缺陷根因）

- packages/views/src/chat/composer.tsx 已有 modelLabel?: string prop，chip 渲染 modelLabel ?? t.modelChip（占位「对话模型」）。
- packages/views/src/chat/page.tsx:121,420 仅透传 modelLabel。
- apps/web/src/chat/ChatRoutePage.tsx 从未传 modelLabel → chip 恒为占位文案。无模型数据获取、无解析逻辑。

## 3. 本切片实现（TDD 先红后绿）

新增 apps/web/src/chat/model-chip.ts（纯函数，逐条对齐 Vue）：
- formatTokenCount / effectiveContextWindow / isDefaultContextWindow / formatContextWindow ← contextWindow.ts 原样移植（默认 200K）。
- listChatModels：type === 'KnowledgeQA' 过滤 ← chatResources.ts:59。
- resolveChatModelChip({ models, agentModelId, notConfiguredLabel })：优先智能体 config.model_id（在列表中才生效；绑定但缺失 → 未配置，不静默回退第一个 ← Input-field.vue:1067-1078 find 语义），否则第一个可用模型（← ensureModelSelection :982-994）；display_name.trim() || name；ctx 缺省 → 200K + is-default。
- MODEL_CHIP_NOT_CONFIGURED：五语 byte-exact（Vue input.notConfigured）。

接线：
- apps/web/src/chat/ChatRoutePage.tsx：client.configuration.models.list()（GET /api/v1/models，失败非致命 → 空列表 = 未配置，对齐 Vue loadChatModels）→ listChatModels 过滤；agentModelId 取所选智能体 config.model_id；解析结果以 modelLabel 传入 ChatPage（page.tsx 当前只透传单 label prop，故 name+规格拼为一个字符串，如 "mock-stream-model 200K"）。
- packages/views/src/chat/composer.tsx：新增 modelContext? / modelContextIsDefault? props 渲染 .wk-chat-model-ctx（Vue .model-selector-ctx 解剖位）；chip 的 aria-label/title 从占位改为已解析标签（Vue tooltip 语义）。page.tsx 的一行透传（modelContext）不在本次授权文件清单内，已向协调者提交需求；透传后 ChatRoutePage 改传两个 props 即可。
- apps/web/src/chat/chat.css：新增 .wk-chat-model-chip .wk-chat-model-ctx(.is-default)（11px、tabular-nums、弱化色、is-default opacity .85 ← Input-field.vue:3645-3655）。
- 无模型/加载中回退：Vue 加载中与无模型均显示「未配置」→ React 同（resolveChatModelChip 空列表/找不到 → 本地化未配置，无 ctx）。
