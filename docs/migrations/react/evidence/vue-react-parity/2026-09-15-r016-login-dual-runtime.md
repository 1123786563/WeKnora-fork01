# R016 登录页双端运行态复核（2026-09-15）

## 环境

- Vue：`http://localhost:5173/login`
- React：`http://localhost:5181/login`
- Chrome 同一窗口、同一中文语言环境、只读访问；两端 HTTP 200。

## 运行态结果

- 两端均渲染 WeKnora 品牌区、官方网站/GitHub/语言入口、登录卡片、邮箱/密码字段、登录按钮、创建账户入口和产品能力摘要。
- 两端 AX 均识别“登录”、邮箱、密码、登录、创建账户等核心控件；React 额外暴露 Login form 容器，不影响可达性。
- 两端视觉截图在同一会话中捕获：绿色品牌背景、左侧能力插画、右侧白色登录卡片和中文文案结构一致。

## 判定

公开登录页当前具备双端运行态和视觉证据，T10 的公开认证入口不再受 Vue 服务不可用阻断。受保护路由、角色变体、Wails/native 和真实写路径仍需各自证据。
