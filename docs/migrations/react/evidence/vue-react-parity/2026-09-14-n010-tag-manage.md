# N010 — FAQ tag management entry and CRUD

Date: 2026-09-14

## Vue baseline

`frontend/src/views/knowledge/components/FAQEntryManager.vue` opens `KbTagManageDrawer` from the tag-filter panel. The drawer supports searchable tags, create, rename, delete confirmation, FAQ counts, and refreshes the FAQ list after a mutation; deleting a selected tag removes it from the active filter.

## React implementation

`apps/web/src/faq/FAQPage.tsx` now exposes the localized `knowledgeBase.tagManageLink` only for contributors/admins. The accessible dialog provides search, create, rename, delete confirmation, loading/error states, FAQ counts, Escape handling for edits, and refreshes tags/entries after successful mutations. `packages/api-client/src/knowledge/documents.ts` adds typed `createTag`, `updateTag`, and `deleteTag` methods using the Vue endpoint paths and encoded identifiers.
