# R252 空间危险区结构对齐（2026-09-15）

真实 Vue/React 设置页对照发现，React 原先将空间删除危险区放在信息列表前，并把确认输入框常驻在页面中；Vue 将危险区放在信息列表末尾，默认只显示标题、说明和删除按钮，点击后再打开确认弹窗。

修正内容：
- `TenantDeleteZone` 移到 `TenantInfoSection` 之后，并在加载/错误状态下隐藏。
- 页面危险区按 Vue 的边框、背景、间距和响应式结构渲染。
- 删除确认输入、确认按钮和取消按钮迁移到 Dialog，未点击删除时不占用页面空间。
- 保留 owner 权限、名称匹配、忙碌态和后端删除接口行为。

浏览器复测（同认证用户、租户、语言和视口）：
