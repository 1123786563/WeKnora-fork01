token from auto-setup; it did not persist the token in the repository.

## Browser evidence

Chrome opened `http://127.0.0.1:18081/platform/chat/session-1`. The rendered
page title was `WeKnora React migration`; the accessibility tree contained
`Sessions`, `New chat`, `Conversation`, a message list, and a message input.
The page displayed `Request failed with status 401`, which is the expected
unauthenticated state for this fresh browser session and proves the React
runtime reached the live API boundary instead of showing a blank shell.

## Remaining T24 gates

This evidence does not prove multi-arch Docker, Nginx deployment, a signed or
installed Wails package, Android/iOS device behavior, the full browser/OS and
role matrix, performance thresholds, or rollback rehearsal. T24 therefore
remains `review`; Vue remains the production/recovery release input.

The isolated Lite run also logged `no such table: tenant_skills` from the
five-minute skill reaper. This is a pre-existing Lite schema/runtime
compatibility gap that keeps T23 Skills/sandbox live acceptance open; it was
not hidden or counted as a React success.
