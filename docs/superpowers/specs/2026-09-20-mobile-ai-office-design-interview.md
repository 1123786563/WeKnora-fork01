# 移动 AI 办公设计访谈台账

日期：2026-09-20。状态：完整设计待最终核对。

## 已确认

- Q1–Q3：WeKnora 是唯一后端；所有任务均在可信 WeKnora 云端执行，文件、Git 与终端操作都属于云端任务执行，资源按空间（Tenant）归属、授权与隔离。
- Q4：移动端以 Paseo 为目标底座，借鉴 Happy 的交互；当前 `apps/mobile` 的 Flutter 实现不作为目标底座。
- Q5：首版包含空间切换、Agent 会话、云端任务、审批、文件与产物、知识资源；管理配置随后补齐。
- Q6：云端执行可读取任务已授权内容，传输和存储加密；不承诺 Happy 式“云端不可读”的端到端加密（E2EE）。
- Q7：一个任务对应一个持续会话，内部可多次运行；继续和重试保留上下文，跨会话聚合的大型项目任务留到后续。
- Q8：云端持续执行；审批可持久等待；完成、失败、待审批均推送，重开补齐。离线仅缓存可读内容和草稿，恢复连接后由用户发送，不自动离线审批。
- Q9：任务默认仅创建者可见，可显式共享给空间成员；工作文件跟随任务权限，发布产物和知识资源按其目标权限控制。
- Q10：首版链路为 Paseo mobile → WeKnora Workbench/Run → WeKnora 云沙箱；Paseo 是交互底座，Happy 仅参考同步、多设备设计，首版不采用 Paseo daemon。
- Q11：共享成员只能只读查看对话、运行及获准文件/产物，不能继续执行、使用终端或代创建者审批；既有后端审批权限仍为权威。
- Q12：任务使用独立持久工作区，同一任务多次 Run 复用；不同任务默认不共享可写目录，须显式导入复用。任务结束后文件保留，计算可休眠并在续用时恢复。
- Q13：闲置计算可休眠、持久文件不删除；空间存储配额超限时限制新增写入，允许查看、导出和清理，首版不按天自动删除任务文件。
- Q14：用户选择目标发布固定版本；原任务保持私有，副本按目标权限可见；修改后须重新发布，不自动覆盖，撤销任务共享不撤销已发布副本。
- Q15：首版验收 iOS 与 Android；Paseo Web 保持可构建，完整 Web 仍由现有 WeKnora 提供，不交付第二套完整 Web。
- Q16：锁屏默认仅推送完成、失败、待审批且不含标题正文；本地缓存按账号和空间隔离加密，退出清理，联网发现撤权后清缓存。离线无法立即撤权，用户可关闭离线缓存。
- Q17：在云工作区克隆、修改、查看 Diff 与创建本地 Git 提交；审批后推送分支并创建 PR，合并由代码平台完成。凭据由 WeKnora 连接管理，不进入聊天产物；不提供 force push 或远端删除分支入口。
- Q18：活跃 Run 的终端仅观察输出；交互终端或手工编辑先停止 Run 并确认停止，结果未知则保持阻断，不假装已停止。
- Q19：任务 Owner 使用个人代码平台 Connection；clone 前检查授权，云工作区修改、Diff 与本地 Git 提交不额外审批。每次 push 分支或创建 PR 均展示 repo、branch、具体变更并审批；只读分享者不得使用凭据。
- Q20：发布目标仅为当前空间的产物资源或指定知识库，按目标权限可见；不跨空间、不提供公开互联网链接，保留下载和导出。
- 原贴文中的 Personal Host、direct relay 与独立 Fastify cloud 不再作为默认架构前提。

## 工程参数与验证缺口

缓存容量、淘汰与恢复属于工程参数。持久卷/snapshot provider、移动缓存加密、共享与发布 ACL、Git 远端写入审批均须实现和真实验证，不能由本台账推定已支持。

## 术语说明

Happy 用于借鉴交互及同步、多设备设计，不构成其原有云端或加密协议的采用。Paseo 仅作为移动 UI 与适配底座；云端执行由 WeKnora Workbench/Run 与云沙箱承载，不采用 Paseo daemon。
