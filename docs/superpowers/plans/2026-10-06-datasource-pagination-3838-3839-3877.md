# 数据源连接器分页防护（#3838 / #3839 / #3877）

日期：2026-10-06 · 分支：fix/datasource-pagination-3838-3839-3877 · 模式：3 个并行实现者 + 验证门（tmux 缺席，匿名子代理）

## 背景

三个数据源连接器的分页循环遇到「服务端游标不前进」时不终止：同一页被无限重取、结果切片无界增长，直到 2 小时任务超时。实测 2 秒内飞书 5.5 万次、GitLab 9.6 万次请求。仓库已有标准防护写法：confluence/client.go:26 `maxPaginationHops = 10000` + :210-225 `seen` 集合（重复游标即报错、超限即报错）。

代码位置（fork 实际路径，issue 写的 `internal/datasource/...` 在本 fork 为 `internal/datasource/connector/moauth/...`）：

- `internal/datasource/connector/moauth/connector/gitlab/client.go`（#3839）
- `internal/datasource/connector/moauth/connector/feishu/core/blocks.go`（#3838）
- `internal/datasource/connector/moauth/connector/notion/client.go`（#3877）

三文件域互不重叠，可安全并行。

## 任务 G：GitLab #3839（X-Next-Page 不前进）

1. `projects()` 与 `tree()` 两条 `for` 循环：`seen := map[string]struct{}` 记录已用页码；`getPage` 返回的 nextPage 若已见过 → 返回 `gitlab pagination made no progress at page %q` 类错误；页数超 `maxPaginationHops = 10000`（包级 const）→ 返回错误。写法对齐 confluence/client.go:210-225。
2. `getPage()` 本身不动（不跨轮状态）。
3. 正常路径行为不变：nextPage == "" 仍为完成信号。

## 任务 F：飞书 #3838（bitable fields page_token 重复）

1. `readBitableRecords`（core/blocks.go）拉字段的 `for` 循环（现有退出：items 空 / !has_more || token 空）：
   - `seen` 记录已用 page_token；新 token 已见过 → 返回 `read bitable fields: ... no progress` 类错误；
   - 页数上限：包级 const（同文件风格，如 `maxBitableFieldPages`，量级与 maxDocumentBlocks/maxTableRows 的防护意图一致，取 10000）→ 超限报错。
2. 「items 空即 break」的防御保留。
3. records 循环（已有 maxTableRows=500）不动。

## 任务 N：Notion #3877（paginatePages / GetBlockChildrenFlat 双缺口）

1. `paginatePages`（SearchPages 与 QueryDatabaseAll 共用 helper）：seen cursor 集合 + `maxPaginationHops = 10000` 页上限；另外补「has_more=true 但 results 为空」的空转防护——连续空页超过小阈值（如 10 页）即报错，防 3 rps 稳定空转到 deadline。
2. `GetBlockChildrenFlat` 同样的 seen + 上限（独立游标循环，同形修复）。
3. 正常退出条件 `!has_more || next_cursor == ""` 保留。

## 测试（沿用各包既有 httptest 假服务端基建）

- gitlab（client_test.go 已有 harness）：恒返 `X-Next-Page: 2` + 非空数组 → projects()/tree() 均返回错误且请求数 ≤ 2；正常翻页用例（1→2→空）行为不变。
- feishu（issue 给了完整 httptest 配方：tenant_access_token + /fields 恒返同 token + /records/search 返回 has_more=false）：2 秒 context 内期望返回错误（而非 deadline exceeded），且 fields 请求次数 ≤ 2、表头不被重复追加。
- notion（client_test.go）：a) has_more=true + 恒定 next_cursor → 错误；b) has_more=true + 恒空 results → 空转阈值报错；c) 正常多页游标推进 → 结果完整、行为不变。GetBlockChildrenFlat 同样至少「重复游标报错」一条。

命令：`go test ./internal/datasource/connector/moauth/connector/{gitlab,feishu/...,notion}/... -count=1`（以各包实际目录为准）
