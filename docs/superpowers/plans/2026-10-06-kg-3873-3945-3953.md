## 契约（已由 team-lead 预先落地，勿改）

`internal/types/extract_graph.go` 的 `GraphRelation` 已新增只读证据字段：

```go
Node1Chunks []string `json:"node1_chunks,omitempty"`
Node2Chunks []string `json:"node2_chunks,omitempty"`
```

语义：Neo4j SearchNode 按「该物理关系的真实端点实例」填充；消费方缺失时回退按节点名聚合 chunks；写入路径不得持久化这两个字段。

## 任务 A（neo4j 域，#3945）：repository.go + 测试

1. 方向修正：`rel.(neo4j.Relationship)` 的 Start 元素 id（v6 driver，API 名先在 module cache 确认，如 StartNodeElementID/StartElementId）与 n/m 的元素 id 比对，Node1=真实起点、Node2=真实终点。
2. 物理关系去重：按 relationship 元素 id seen 集合，同一物理关系只解码一次（两 seed 端点命中不再产出两条反向关系）；真正互逆的两条物理关系 id 不同，天然保留。
3. 同名节点合并：nodeSeen 改按名字合并——同名实例的 chunks/attributes 并入已有条目（列表内去重），而非跳过；每个文档实例的证据都保留。
4. 填充 Node1Chunks/Node2Chunks：取该行 n/m 实例各自的 chunks。
5. 测试（repository_test.go，先看既有 fake 记录回放基建）：issue 场景 doc1/doc2 同名 Acme/Shanghai 两文档、HEADQUARTERED_IN 与 HAS_BRANCH_IN——断言方向与库内一致、每条物理关系恰好一次、节点含两文档 chunks、关系带端点 chunks。

## 任务 B（工具域，#3873 + #3953 + #3945 过滤部分）：query_knowledge_graph.go、model_output.go + 测试

1. #3873 截断可见性（上限值、去重语义、检索行为不变）：
   - 去重循环计数被丢弃的关系；命中上限时 `Data` 增加 `relations_total` / `relations_omitted`（未命中不下发，沉默即完整）；主行改 `Found 30 of 42 relations`；Output 追加截断说明段（提示收窄到单实体）。
   - annotateGraphResult 在 `<retrieval>` 图谱视图渲染 `<graph_truncated relations_shown="30" relations_total="42">`（对齐既有 `<omitted count>` / `<partial_failure>` 写法）。
   - chunk 展示上限 10 同理最小处理：命中时 `Data` 加 `evidence_total`/`evidence_omitted` + Output 一行说明。
   - 实体词上限 8：命中时 `Data` 加 `dropped_terms`（本地可得，零成本）。
2. #3953 整库验证：关系证据校验对所有 scope 生效（含 whole-KB）。实现要点：
   - 校验预算与展示预算分离：展示 chunks 仍 10 条封顶；校验用全量节点 chunks（或关系端点 chunks）并集查 `ListChunksByIDOnly` 判存活（KB 归属 + IsEnabled + 文档存在，复用 loadGraphEvidence 的 titles 检查逻辑）。
   - 关系通过 = 两端点的 Node1Chunks/Node2Chunks（缺失时回退该名字节点的聚合 chunks）与存活 chunk 集合均有交集。
   - chunkRepo 为 nil 无法校验时：图谱分支不下发未校验关系（丢弃 + Output warning），文本检索结果照常返回（issue 明示该取舍）。
3. #3945 过滤修正：`relationsBackedBy` 从「按节点名聚合 chunks」改为优先用 rel.Node1Chunks/Node2Chunks（缺失回退原名聚合逻辑），使文档/标签 scope 检查真实端点证据。
4. 测试（query_knowledge_graph_test.go / _graph_test.go 既有基建）：
   - 42 条关系实体 → `relations_total=42`、`relations_shown=30`、输出含截断标记、annotateGraphResult 渲染 graph_truncated；
   - 整库查询 + 两端点 chunk 全部禁用/删除 → relations 为空（文本结果可保留）、不输出未校验关系；
   - 关系由第 11 条候选 chunk 支撑 → 不因展示上限被误杀；
   - doc scope + 同名跨文档 + 关系带端点 chunks → 只留该 doc 端点证据支撑的关系（用 Node1Chunks 判定，而非名字聚合）。
