# M03: Task list, detail and workspace navigation

## Parent

Parent #3

## What to build

Let a member browse WeKnora-backed Tasks and open their task-local conversation, files, Git, terminal and artifacts while preserving the server's task, scope and access truth.

## Acceptance criteria

- [ ] A Task maps to its persistent WeKnora session and retains task-scoped navigation.
- [ ] Owner and read-only views render only actions permitted by the server projection.
- [ ] Direct, back and refreshed navigation rehydrates through the current workspace scope.
- [ ] Forbidden or stale scoped data is not left visible.

## Blocked by

- M02: Trusted login and workspace scope.
