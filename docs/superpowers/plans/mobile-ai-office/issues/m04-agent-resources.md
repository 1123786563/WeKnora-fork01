# M04: Agent directory, knowledge and attachment selection

## Parent

Parent #3

## What to build

Provide a trusted workspace-scoped picker for WeKnora Agents, permitted knowledge resources and verified attachments, so a user can prepare an explicit task input without submitting it automatically.

## Acceptance criteria

- [ ] The picker reflects the current workspace's Agent and knowledge availability.
- [ ] Only server-ready attachments can be included in a prepared task input.
- [ ] Changing workspace clears old resource selections.
- [ ] Revoked or unavailable resources cannot be staged as a successful input.
- [ ] The attachment import control retains documented Paseo source provenance and only receives app-owned picker props.

## Blocked by

- M02: Trusted login and workspace scope.
