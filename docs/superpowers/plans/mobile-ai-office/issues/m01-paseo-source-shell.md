# M01: Paseo source-controlled mobile shell

## Parent

Parent #3

## What to build

Create an attributable Paseo-derived mobile presentation shell for WeKnora that uses only selected UI code, retains its source provenance, and leaves cloud state and execution authority with WeKnora.

## Acceptance criteria

- [ ] Each imported Paseo module records its approved source revision, origin, license and local adaptation reason.
- [ ] The mobile shell provides Home, Tasks, Agents and Me navigation using app-supplied callbacks.
- [ ] No Paseo daemon, cloud protocol, persistence authority or hidden execution state is introduced.
- [ ] Unit and static evidence are recorded separately from iOS and Android device evidence.
