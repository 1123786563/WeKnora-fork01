## What to build

Give an authorized task viewer a safe mobile Files surface that lists, reads, and downloads permitted workspace files.

## Acceptance criteria

- [ ] File paths cannot escape the task workspace and non-regular or oversized files are not exposed as normal downloads.
- [ ] Backend tenant and task access checks apply before every list, read, and download.
- [ ] A failed mobile download is not shared as a completed file.
