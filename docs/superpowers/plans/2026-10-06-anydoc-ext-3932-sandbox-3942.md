## 背景与取舍

- #3932：anydoc 链路 Go 侧 `extensionFor`（internal/modules/knowledge/docparser/anydoc/backend_cgo.go:186）用 `mime.ExtensionsByType`（随环境 /etc/mime.types 漂移），Rust 侧 `extension_for`（third_party/anydoc-go/src/asset_links.rs:72）是固定 7 项+.bin。装了 media-types 的镜像上 image/emf→.emf vs .bin，markdown 链接与 refMap 精确匹配失败 → EMF/WMF 图片静默丢弃。修法=Go 侧镜像 Rust 映射，确定性化，零环境依赖。
- #3933（anydoc 下 EMF/WMF 不再光栅化）：需在 Go/Rust 路径引入光栅化能力（老路径靠 Python+ImageMagick），属基础设施决策，**本轮不做，留裁决**。
- #3942/#3910：docker 空闲清扫器与首操作竞态 → makeDir invalid_request 且 stderr 为空（#3910 同签名同根因，并票）。issue 自述修法供维护者定夺（A=租约核对 / B=换绑重试）。本轮范围：
  1. 无争议诊断增强：makeDir/exec 错误带 exit code 与 stderr 空标记（不再在冒号处截断）；
  2. 方向 B（in-flight 换绑重试）**仅当**既有接缝（CanReplaceRemoteBinding / 绑定替换语义）能小步接入且可用假容器测清时落地；否则诊断增强交付+竞态分析记录，A/B 留裁决。
