# 02｜小程序页面与交互说明

离线交互线框；所有账号、任务、余额、价格和文件均为虚构示例。没有连接真实后台、登录或支付。

主导航：工作台 / 任务 / 知识 / 我的。每页可在 wireframes.html 左侧切换，也可从 wireframes/pages 的独立 HTML 入口打开。窄屏只显示手机内容，宽屏包含页面导航与设计说明。

## 全局规则

顶部始终能识别当前页面；关键操作标明空间；一级Tab使用固定底部导航，聊天与审批采用独立底部操作。输入框和按钮有清晰标签，重点操作有二次确认。列表分页、下拉刷新、权限和错误状态应在Taro实现中接入真实API；本原型仅模拟交互。

## 01｜登录与账号绑定

入口：`wireframes/pages/01-login.html`

**目标**：用微信身份或已有账号进入同一 SaaS，不暴露租户 API Key。

**布局**：上部品牌与定位；中部微信入口/账号表单；底部隐私说明与绑定入口。

**字段**：微信登录按钮、账号/密码、绑定选项、隐私与服务协议、错误提示。

**按钮与事件**：同意协议后模拟登录；已有账号登录；选择“绑定已有账号”展示双侧身份确认；进入空间选择。

**空/错/边界状态**：未同意协议不可登录；微信 code 过期要重新获取；重复绑定与注册关闭单独提示。

**权限约束**：匿名可查看协议；平台 token 仅来自后端；绑定不能以昵称或用户自报手机号推断。

**接口对照**：E auth/login、auth/me、auth/refresh；N auth/wechat/mini/login 与绑定协议。

## 02｜选择工作空间

入口：`wireframes/pages/02-workspace.html`

**目标**：明确当前租户与用户角色，处理尚无空间的用户。

**布局**：标题说明；纵向空间卡片；选中空间说明；底部进入按钮；加入入口。

**字段**：个人空间、团队空间、角色标签、当前选中状态、加入邀请、创建空间。

**按钮与事件**：选择空间后点击进入；切换时清理示例任务和对话状态；创建空间展示提案说明。

**空/错/边界状态**：无成员关系显示创建/加入；被移除或暂停的空间不可进入；切换失败保持原空间。

**权限约束**：tenant_id 不是授权凭证；服务端验证 membership；组织分享不等于切换租户。

**接口对照**：E auth/me、auth/switch-tenant、POST tenants、me/invitations。

## 03｜工作台

入口：`wireframes/pages/03-home.html`

**目标**：快速使用 Agent、继续对话并处理需要关注的执行。

**布局**：顶部空间切换；意图输入；2列 Agent 捷径；待处理卡；最近活动；底部4Tab。

**字段**：当前空间、欢迎区、输入任务意图、常用 Agent、待处理提醒、最近会话、可用额度。

**按钮与事件**：切换空间；打开 Agent；新建任务；继续对话；打开待审批任务；查看用量。

**空/错/边界状态**：首次使用显示示例问题；聚合部分失败只影响对应卡片；无执行能力时仍可知识问答。

**权限约束**：只聚合本人可见数据；余额与权限由服务端返回，不能根据角色名猜测。

**接口对照**：E 会话/知识/商业API；N 可选 workbench/home；N 完整部署能力声明。

## 04｜Agent 列表

入口：`wireframes/pages/04-agents.html`

**目标**：选择有权限使用的已配置 Agent，而不是在手机重做配置后台。

**布局**：搜索框；分段筛选；纵向Agent卡片；卡内用途与能力标签。

**字段**：搜索、常用/团队/全部筛选、名称、简介、能力标签、可用状态。

**按钮与事件**：搜索名称；切换筛选；点卡片进入 Agent 详情；不可用展示原因。

**空/错/边界状态**：未安装/禁止使用/运行目标离线与空列表区分；不展示模型 API Key。

**权限约束**：后台返回可见 Agent 集；不可用不能通过输入 agent_id 绕过。

**接口对照**：E custom Agent 能力；通过当前共享 configuration/Agent端点接入，MP00确认准确映射。

## 05｜Agent 详情 / 发起任务

入口：`wireframes/pages/05-agent.html`

**目标**：在已配置、获授权的执行范围内提交一次任务。

**布局**：Agent信息卡；任务文本；预算与运行环境；边界说明；底部提交。

**字段**：Agent介绍、能力、用户任务文本、平台目标、预算上限、输入范围说明。

**按钮与事件**：提交文字任务生成固定request_id；进入执行页；仅聊天能力则转问答。

**空/错/边界状态**：目标不可用/预算不足/提交未知状态；先查询原request_id，不新建重复任务。

**权限约束**：target/workspace为服务端授权选择；不向现有StartExecutionInput私塞attachment_ids。

**接口对照**：E POST workbench/executions；GET workbench/executions/requests/:request_id。

## 06｜知识 / Agent 对话

入口：`wireframes/pages/06-chat.html`

**目标**：自然语言问答，展示引用、工具摘要和临时附件。

**布局**：导航与知识范围；可滚动消息区；引用卡片；固定底部输入条，不与Tab重叠。

**字段**：会话标题、知识范围、气泡、引用、工具进度、输入框、附件、发送与停止。

**按钮与事件**：输入并模拟增量回复；打开引用文档；临时附件说明；打开历史；主动停止输出。

**空/错/边界状态**：网络断开显示恢复/重试；空回答与无引用区分；不将停止本地订阅等同取消后台执行。

**权限约束**：仅本人会话；引用文档需再次鉴权；只展示执行摘要、不显示私有推理。

**接口对照**：E sessions、messages、knowledge-chat/agent-chat、attachments、continue-stream（需验证）。

## 07｜任务中心

入口：`wireframes/pages/07-tasks.html`

**目标**：跨设备查看本人任务，按状态定位运行和待处理事项。

**布局**：标题与新建；状态筛选；任务卡列表；恢复说明；底部4Tab。

**字段**：全部/运行中/待处理/已完成、任务标题、Agent、状态、更新时间、恢复标识。

**按钮与事件**：筛选任务；打开详情；新建任务；待处理跳审批。

**空/错/边界状态**：空任务/筛选无结果/无权限/服务未装配分开；离线只读缓存有明确时点。

**权限约束**：分页和统计基于owner+tenant，不是全租户管理员任务墙。

**接口对照**：N GET workbench/executions 列表；E 单run详情/快照。

## 08｜执行详情

入口：`wireframes/pages/08-execution.html`

**目标**：看进度、恢复状态、追加指令、取消或进入审批。

**布局**：状态大卡；任务信息；步骤时间线；待处理区域；底部操作。

**字段**：run状态、连接状态、任务正文、阶段摘要、待处理卡、产物、执行/结算状态。

**按钮与事件**：模拟断网并恢复；打开审批；追加文字steer；二次确认取消；模拟完成后查看产物。

**空/错/边界状态**：seq缺口或schema不支持→重新同步；取消已完成run要刷新状态；结算中不能当异常重复计费。

**权限约束**：单run归属与capabilities检查；操作带expected_revision；不能向source-events写客户端伪事件。

**接口对照**：E execution/get/snapshot/events/interactions/commands。

## 09｜审批与风险确认

入口：`wireframes/pages/09-approval.html`

**目标**：用户理解动作对象与影响后，只批准当前这一次操作。

**布局**：风险提示；动作摘要；影响/对象；参数折叠区；固定拒绝/仅此次同意。

**字段**：任务/空间、待批准动作、目标、必要参数、风险说明、拒绝理由、有效性。

**按钮与事件**：同意前二次确认；拒绝并说明原因；模拟他端处理冲突后刷新。

**空/错/边界状态**：已处理/过期/版本冲突禁止重复提交；不显示永久允许或默认同意。

**权限约束**：来自服务端的可处理interaction；预算扩展不等于外部写操作授权。

**接口对照**：E GET :run/interactions；POST interactions/:id/decisions；请求体沿用真实类型。

## 10｜任务产物

入口：`wireframes/pages/10-artifact.html`

**目标**：获取后台真实保存的产物，不在小程序运行生成代码。

**布局**：文件信息；安全标记；文本预览；下载/返回操作。

**字段**：文件名称、类型、来源任务、授权状态、内容摘要、下载、返回任务。

**按钮与事件**：查看示例文本；模拟下载提示；返回执行详情。

**空/错/边界状态**：文件过期/撤销/无权限；HTML与脚本只显示安全摘要或源码说明。

**权限约束**：通过受鉴权资源接口下载，不保存永久公开地址。

**接口对照**：E sessions/:id/artifacts、message artifacts/download；跨run映射按真实session/message确认。

## 11｜知识库

入口：`wireframes/pages/11-knowledge.html`

**目标**：找可访问的知识库并进入检索或问答。

**布局**：空间/搜索；筛选；知识库卡；最近文档；底部4Tab。

**字段**：搜索、我的/空间/共享、知识库卡片、最近更新、可操作状态。

**按钮与事件**：搜索；选知识库；点问答；进入导入流程。

**空/错/边界状态**：共享只读库禁止上传；空库提示导入；未就绪不能承诺可检索。

**权限约束**：知识共享范围和tenant范围按后端组合验证。

**接口对照**：E knowledgeBases共享API与domain筛选；具体字段按真实返回投影。

## 12｜知识库详情

入口：`wireframes/pages/12-kb.html`

**目标**：查看文档与处理状态，选择基于此库提问。

**布局**：知识库头部；双操作；文档搜索；状态列表。

**字段**：名称、说明、文档列表、解析/就绪/失败状态、上传入口、库内提问。

**按钮与事件**：打开文档；问答；导入；查看解析状态说明。

**空/错/边界状态**：上传完还未解析；失败条目显示可诊断说明；权限变动需刷新。

**权限约束**：上传权限以实际知识库授权为准，不能仅从菜单判断。

**接口对照**：E knowledge document list / processing / settings相关共享API。

## 13｜添加知识

入口：`wireframes/pages/13-upload.html`

**目标**：通过文件或URL将内容写入当前有权限的知识库。

**布局**：目标说明；导入方式；文件占位/URL；进度；确认与返回。

**字段**：目标库、文件/链接选择、文件信息、上传进度、解析说明、提交。

**按钮与事件**：模拟选择文件；切换URL输入；提交显示上传与解析两段状态；返回文档列表。

**空/错/边界状态**：格式/大小不允许、网络失败、URL抓取失败；不将临时聊天附件自动入库。

**权限约束**：明确目标库与权限；URL安全策略由后端执行。

**接口对照**：E knowledge upload/import共享API；A Taro.uploadFile + NativeFileSource。

## 14｜文档 / 引用详情

**布局**：文件元信息；引用高亮块；正文片段；提问/下载。

**字段**：标题、所属知识库、来源位置、引用段落、完整内容入口、提问按钮。

**权限约束**：文档级鉴权；模型生成URL不直接当可信来源。

**接口对照**：E knowledge document/preview与chat reference领域映射。

## 16｜用量与套餐

入口：`wireframes/pages/16-usage.html`

**目标**：解释可用/预占/退款冻结，并在权限允许时选择套餐报价。

**布局**：余额卡；用量条；套餐卡；政策待核验提示；订单入口。

**字段**：套餐、可用/预占/退款冻结、统计时点、用量示例、计划卡、购买资格。

**按钮与事件**：选择示例套餐进入报价；查看账单；无权限显示原因。

**空/错/边界状态**：过期报价重取；商品/终端不支持购买；不给外部绕过支付链接。

**权限约束**：由后端billing权限与通道资格控制；金额/credits使用字符串真值。

**接口对照**：E commercial summary/plans/usage/quotes；N 合规通道可用性。

## 17｜报价与支付

入口：`wireframes/pages/17-checkout.html`

**目标**：在已核验的购买能力下确认服务端报价并调起正确支付通道。

**布局**：订单信息；金额与权益；合规通道状态；底部确认；清晰模拟按钮。

**字段**：空间、商品、报价金额、权益、有效期、购买权限、通道和状态。

**按钮与事件**：默认通道待核验不可购买；点击演示开关仅模拟已开通；提交→付款待确认订单。

**空/错/边界状态**：过期/权限不足/用户取消/渠道未知状态；不以端回调给权益。

**权限约束**：AI次数与会员先评估虚拟支付；合规普通服务才使用JSAPI；签名与openid从后端得到。

**接口对照**：E quotes/orders；N typed mini checkout / 虚拟或JSAPI渠道适配。

## 18｜订单与履约结果

入口：`wireframes/pages/18-order.html`

**目标**：分别显示支付与权益发放状态，避免重复购买。

**布局**：两阶段状态；订单详情；状态说明；查询和返回。

**字段**：订单号、付款状态、履约状态、金额、商品、时间、重查按钮。

**按钮与事件**：模拟已付款待履约；模拟后端履约确认；刷新原订单；返回用量。

**空/错/边界状态**：支付超时不新建重复订单；退款状态不自算；attention说明需处理。

**权限约束**：仅当前空间可见且授权的订单；示例模拟不代表真实支付。

**接口对照**：E GET commercial/orders/:id；OrderView.payment 与 fulfillment。

## 20｜异常与能力状态

入口：`wireframes/pages/20-states.html`

**目标**：展示加载失败、服务未开通、权限拒绝与断流恢复的不同表现。

**布局**：状态筛选；图形占位；原因与恢复；设计验收说明。

**字段**：错误原因、恢复动作、请求标识、只读缓存时点、能力状态。

**按钮与事件**：切换异常类型；重试；去执行页恢复；去登录。

**空/错/边界状态**：禁止把404/503/forbidden显示成“暂无数据”；网络断开不创建新run。

**权限约束**：不展示后端堆栈、凭证或敏感参数。

**接口对照**：E ApiError与ExecutionDTO.capabilities；N 完整部署能力声明。
