## 4. 原型与生产差异

所有账号、邀请、任务、文件、额度、价格和订单均为虚构。审批、支付和解析演示按钮只改变本地状态；文件下载只生成本地示例Markdown。模拟作用域清理与任务对账不证明真实服务已具备这些安全属性。

HTML中的微信系统区域是视觉占位；真机应读取真实尺寸，不能重复绘制另一套系统胶囊。生产页面需按详细设计拆成Taro组件和控制器，不应以整页截图或WebView代替。
