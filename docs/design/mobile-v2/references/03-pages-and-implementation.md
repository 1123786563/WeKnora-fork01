# 页面线框与增量实施计划

关联原型：`wireframes.html`。原型是本稿提出的信息架构与交互演示，不是对仓库当前页面的截图，也不代表API已实现。所有金额/任务/节点/资料为模拟数据，不涉及实际财务记录或外部操作。

## 1. 信息架构

```text
登录 / 服务器（高级选项） / 空间选择
└── 工作台
    ├── 新建任务 → Agent选择 / 资源 / 目标 / 预算 → 对话
    ├── 待处理 → 审批 / 问题 / 预算 / 授权
    ├── 执行详情 → 时间线 / 产物 / 消耗 / 取消
    └── 通知收件箱 → 重新授权的详情
└── 会话
    └── 对话 → 执行详情 / 引用 / 文件 / 语音
└── 资源
    ├── Agents
    ├── 知识与文档
    ├── 连接器
    ├── 任务成果
    └── 远程目标（能力开启时）
└── 我的
    ├── 当前空间 / 切换空间
    ├── 空间用量与权益（按角色）
    └── 通知偏好 / 隐私 / 退出
```

## 2. 18 个页面定义

| ID / 页面 | 页面组成与字段 | 主要按钮和去向 | 数据/接口与门槛 |
| --- | --- | --- | --- |

| M03 工作台 | 当前空间、任务主入口、执行计数、待处理、最近产物 | 新建、审批、执行详情、通知 | overview为建议聚合API；W11/UX02 |
| M04 会话列表 | 搜索、最近会话、Agent、最新摘要、任务状态 | 会话→M07；新建→M05 | 复用会话列表；任务摘要按权限聚合；W10/W11 |
| M05 新建任务 | Agent、提示、附件、可选知识、目标、预算上限 | 选择Agent→M06；选择目标→M15；提交→M07 | 先准备会话/附件再start；request_id持久化；W04/W06/W10 |

| M07 对话 | 消息、工具/引用、状态条、执行详情入口、输入/附件/语音 | 发送、查看审批、看引用、看结果 | 产品VM+快照+SSE；W09/W10/W12 |
| M08 执行详情 | Run、request、三个状态、目标、预算/已用、时间线 | 返回对话、查看产物、申请取消、查询状态 | 单Run/snapshot/commands/lookup；unknown不重复start |
| M09 审批详情 | 明确动作、连接账号、目标、内容、风险、有效期/revision | 批准一次、拒绝、刷新 | interaction当前授权；批准前显示二次确认；W05 |
| M10 收件箱 | 待处理、完成、失败、额度提醒 | 点击→授权后进入资源 | notification/inbox读模型；W13–W16 |
| M11 资源 | Agent、知识、连接器、成果、远程节点入口 | 对应详情 | 不复制Web全部管理菜单；各资源原接口优先 |
| M12 知识详情 | 知识库、来源、文档列表、更新时间、引用摘录 | 用此知识提问、文档预览 | 知识权限和索引可用性；W25/W28 |
| M13 连接详情 | Provider、个人/空间连接、状态、允许动作、限制 | 授权/重新授权、撤销连接 | 产品连接API；不直连OC管理端；T13/T18门禁 |
| M14 产物 | 文件名、版本、来源Run、预览、大小、权限 | 预览、系统分享/下载 | 版本化产品产物；受控签名URL；W25–W28 |
| M15 执行目标 | 平台/托管节点/个人节点、能力、在线状态、工作目录 | 选择目标，禁用未就绪目标 | target/workspace API；W17–W24 |
| M16 语音 | 录音/转写、可编辑文本、发送确认 | 转写→编辑→普通文本提交 | 首版W29；实时会话W30/W31另验 |
| M17 我的 | 用户、空间、角色、用量入口、通知偏好、退出 | 空间→M02；用量→M18；退出→M01 | scope/设备注销；billing角色独立 |
| M18 空间用量 | 空间账户、额度、任务预算与已结算消耗区别、账单角色 | 返回；受限时联系账单管理员 | 复用商业域；本稿没有实现支付入口 |

### 审批

先显示具体动作与授权边界，不能只放“同意/不同意”。原型展示一次性确认对话框；真实实现必须绑定服务端冻结的目标/内容/摘要/revision。线框中的通知只是提醒，点击通知不能自动批准。目标是将业务决定与普通导航分开。

## 4. 交互与异常状态矩阵

| 状态 | 必须表现 | 禁止表现 |
| --- | --- | --- |
| 空空间 | 当前空间为空、选择Agent开始 | 显示上一空间的任务/产物 |
| 弱网/离线 | 顶部离线提示、缓存时间、草稿保留 | 无限spinner、自动补发危险指令 |
| 启动结果未知 | 显示同一request_id与查询状态按钮 | 默认生成新ID再次开始 |
| 审批冲突 | 另一设备已处理，刷新详情 | 同一旧决定自动重发 |
| 无权限 | 说明权限不足，隐藏敏感正文 | 显示完整目标再提示403 |
| 能力不可用 | 禁用并给原因，可选已授权替代目标 | 点击无效或提示假成功 |
| 游标过期 | 同步快照后续接，不清空用户草稿 | 重启Agent或重复append旧消息 |
| 切账号 | 撤销旧推送、隔离缓存、旧响应失效 | 向新用户显示旧通知内容 |
| 取消待确认 | 停止请求已提交，等待执行方确认 | 立刻显示已停止/已退款 |
| 文件未扫描 | 展示处理中、不可供Agent读取 | 根据扩展名当作安全文件 |

HTML 顶部提供“正常 / 离线 / 审批冲突 / 无权限 / 启动未知”场景。它们是可复现的交互说明，不运行真实恢复、审批、上传或认证。

## 6. 交付切片与顺序

**切片0：校准与修复。** UX00并行于静态线框，修正版本组合、协议shape、SQLite适配、能力/审批VM；已有实现先复验，不为制造RED破坏正确代码。

**切片1：平台执行闭环。** W01–W12及UX01–UX05，先普通产品身份+一个平台Agent。使用真实接口完整验证创建会话/准入/事件/审批/结果/恢复。此处是端到端里程碑，不直接声称已经达到core发布profile。

**切片2：核心可交付与移动资源。** W13–W16通知，W33–W37的core门禁；按选择加入W25/W27/W28与UX06、UX07。没有远程场景时不以W26阻塞平台已有附件，但不得宣布remote产物验收通过。

**切片3：受控远程与听写。** W17–W24/W26与remote子门禁；W29可先交付确认式听写。个人节点W23独立验收，不能凭托管目标通过就开放任意个人机器。

**切片4：实时语音与完整保留。** W30/W31、W32与继承H24–H33等能力；full_happy需要对应真实实现，不以“按钮置灰”代替保留。所有最终发布仍走激活profile的依赖闭包。

具体执行以原 task-index.json / DAG 的直接依赖、条件依赖、环境依赖为准。本节不改变依赖边；新增接口冲突须先修正文档再分派。

## 7. 可并行与必须串行的工作

契约稳定后，原生组件/页面与Go聚合读模型可并行；通知服务端与资源渲染可以在无共享写文件时并行；远程探针与平台UI可并行且不互相假装提供真实服务。每条分支须有明确输入/输出fixture。

路由/DI、ConversationScreen、App根layout、pnpm-lock、Go依赖、两套迁移编号、预算/事件事务、台账保持单写者。两个worktree不等于两个任务不会语义冲突。集成后重跑真实契约测试，而不是只 cherry-pick 后各自“之前绿了”。
