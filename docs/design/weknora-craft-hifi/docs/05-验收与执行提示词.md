## 3. 证据目录与状态标准

每项任务建议保存：

```text
docs/craft/evidence/<task-id>/
  result.md          # 结论、范围、缺项、reviewer
  environment.json   # commit、依赖锁、镜像digest、浏览器版本
  fixtures.json      # 不含真实隐私或密钥
  unit.log
  integration.log
  screenshots/       # 同宽度、同状态
  trace-ids.txt      # 脱敏，不是原文
```

`result.md` 必须区分 passed / failed / blocked / not_run。实际业务验收不是按截图数量判断，而是每条语义能否用正确证据支撑。静态mock、代码存在、编译成功、真文件可读、权限反例通过是不同等级。

生产网页最低门：A01–A33及A37–A40适用项通过；Office类型分别追加A34/A35/A36及对应修改/历史下载。任何安全阻断项失败不得用平均分抵消。
