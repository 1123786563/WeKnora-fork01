图标为离线环境已安装的Font Awesome Free SVG子集，具体许可见 `design/THIRD_PARTY_NOTICES.txt`。没有分发字体。品牌区使用文字WeKnora和库图标占位品牌标记；生产接入时必须复用仓库的正式Logo资产，不把该占位图标视为品牌规范。

所有企业名称、文件、销售数据、时间与版本为设计演示。未读取个人财务或真实企业资料。上传演示仅取得浏览器提供的文件名与大小，不读取文件正文或上传服务。
