# WeKnora Craft Implementation Plan / 详细实施计划

> **For agentic workers:** 按本计划逐任务执行；使用 `superpowers:subagent-driven-development` 或 `superpowers:executing-plans` 的独立任务与评审方式。任务步骤采用checkbox；本包没有替用户执行生产仓库变更。

**Goal:** 在现有WeKnora内完成assistant-ui真实接入、可恢复作品链路与符合现有蓝绿主题的Craft产品界面。

**Architecture:** 保留React共享包与Go应用服务。tRPC-Agent-Go拥有主Run，OpenCode为委派执行器。界面通过现有Controller/REST/SSE取得事实，不创建第二套主状态。

**Tech Stack:** 现有React/Vite、@weknora/ui、assistant-ui、Go/Gin、tRPC-Agent-Go、OpenCode；依赖锁与运行镜像以基线核对为准，不顺带升级。

**Spec:** `01-详细设计.md`、`02-UI设计与令牌.md`、`04-API与状态契约.md`。

## Global Constraints

- 基线 `0cba2f85f8998a28691d564690a1261dcc041643`；开工先核对实际HEAD。
- 服务器派生tenant/user；现有Session/Run为唯一主事实。模型和客户端不能选择任意执行身份。
- 断流只读恢复；unknown不等于失败/成功；旧generation/fence不能发布。
- 查看版本≠恢复基线；版本发布后不可变；可下载≠可恢复。
- 继承蓝色 `#2E6DE6`、绿色 `#07C05F`，Craft作用域内增加别名，不覆盖全局primary。
- 首条真实Web链路之前完成有限预算/时长/网络与权限隔离；收费仍遵守宿主商业门禁。
- 模板/Office/分享等能力未通过对应验收时保持关闭；HTML视觉样例不是实际文件生成证据。
- 所有新路径为建议；已存在同职责实现则补齐，不制造平行模块。所有目标测试命令未在本包针对业务仓库运行。

## 3. 并行与文件锁

T001后可分三轨：A前端（T002–T012），B执行（T013–T018），C设计/测试（T003/T004与后续fixtures）。T019/T020可在前端完善期间构建；T024必须等真实依赖汇合，不能用mock越过门禁。T025/27/29可并行，但固定Office镜像、manifest、shared preview修改由单一负责人集成。T031/32具备依赖后可提前，不要求Office全做完。

| 共享热点 | 默认负责人/任务 | 规则 |

| contracts/DTO | T002 | 冻结后变更先提合同补丁，通知所有依赖 |

## 4. 调度与状态台账

机器可读索引 `tasks.json`。初始状态全部 `planned`，只表示设计已拆分。实施状态建议：planned → ready → in_progress → implemented → verified → reviewed → merged；blocked必须填阻塞原因与解除条件。不能将“文件存在”“PR已开”“测试通过”“已发布”压缩为同一个完成状态。

推荐分支名 `craft/<task-id>`。共享文件锁冲突时暂停写文件，但可读代码或准备失败fixture。提交内容限定本任务，合并前跑锁拥有者的回归集。仓库实际多工作区机制由执行环境决定，不声称本包创建了任何Git分支。

## 5. 真实命令与计划命令

当前根脚本已存在 `pnpm run test:shared`、`pnpm run typecheck:web`、`pnpm run build:web`，但Craft测试未完整包含在显式glob中。T001新增或核对 `test:craft:shared` / `test:craft:web`，并核对Playwright runner配置。任务中单个tsx/node:test、Go `-run`、Playwright路径为建议新测试入口，必须真实收集、失败原因正确、然后通过；空跑不通过。

涉及真实OpenCode、生成器和浏览器的测试需要固定依赖/镜像及专用测试凭据，凭据不进入本包、日志或Git。CI中不可用时状态记blocked/not_run而非绿色跳过。

## 6. 交接

每个任务卡可独立交给一个执行者，但必须同时附规范与依赖产物。先做T001，再允许按合同并行；首个产品里程碑是T024，而非“页面看起来像”。`05-验收与执行提示词.md` 给出总控与单任务提示词。
