# WeKnora Craft UI 风格与设计令牌

**版本 1.0 / 2026-09-18 / 基线 `0cba2f85…`**

## 1. 视觉方向

延续现有 WeKnora 的**浅灰工作空间、白色面板、蓝色品牌/导航、绿色创作动作**。不是重新品牌化，也不沿用上轮低保真临时 `#235E50` 墨绿色。整体采用紧凑而有层次的企业工具风格：以细线分区、少量投影、清晰文本和真实内容形成层级，不用营销式大渐变或大面积装饰。

结构来自上轮首页、双栏工作台、来源与版本抽屉；本轮提升字阶、组件密度、品牌色、图表、文件格式预览和状态反馈。它不是对现有任意 WeKnora 页面的逐像素复刻，新增 Craft 组件属于本次设计。

### 2.1 两项有意的可访问性修正

亮绿色上放小号白字，不能因“原来如此”就视为足够可读。本包保留绿色背景，使用现有深色 `#172033` 作前景，并用深绿色细边界明确按钮轮廓。该处理仅在 Craft 作用域生效，不全局重写旧按钮。

第二项：原始次文本 `#66758B` 在白底约4.68:1，但在React画布 `#F7F9FC` 上约4.44:1，略低于正常字号目标。默认次文本改用现有 `#506078`（muted-strong）并增加 `--craft-secondary-text` 用途别名；画布对比度约6.06:1。原始muted仍保留在色板/来源映射，不发明新色。

正常字号文本目标对比度至少 4.5:1；大号文本至少 3:1，依据 W3C WCAG 对比度条目 [U03]。本包的具体计算结果见 `qa/contrast-results.json`。本包不声称整个 WeKnora 已取得无障碍合规认证。状态同时使用图标、文字、颜色，不能只用红绿区分。

### 2.2 生产样式接入顺序

```text
现有 design-tokens 生成样式
  → packages/ui/styles.css 与 theme.css（遵从宿主既有加载顺序）
  → Craft 作用域别名
  → Craft 组件样式
```

使用 `.wk-craft` 包裹功能域。生产优先引用源变量，fallback 只为独立 HTML/隔离测试服务。不应复制原始主题全量覆盖 `:root`。扩展 token 在源包集中维护，再生成 CSS/JSON；不要让原型构建脚本成为生产的第二事实来源。

示例：

```css
.wk-craft {
  --craft-brand: var(--color-primary, #2e6de6);
  --craft-accent: var(--color-accent, #07c05f);
  --craft-canvas: var(--color-canvas, #f7f9fc);
  --craft-ink: var(--color-ink, #172033);
  --craft-action-fg: var(--craft-ink);
}
```

`tailwind-bridge.css` 提供 Craft 专用 utilities，不能把本例理解为需要替换现有 Tailwind 配置。宿主 `theme-mode` 暗色链路仍需单独覆盖测试；本轮仅交付浅色，没有隐藏的“完整暗色支持”承诺。

## 3. 字体、字阶与信息密度

字体采用宿主 `--app-font-family`，fallback 为系统中西文字体；代码采用 `--app-font-family-mono`。不联网请求字体，不附字体文件。不同系统文字宽度会略有差异，正式截图基线固定浏览器/字体环境。

| 用途 | 字号/行高 | 字重 | 约束 |
|---|---|---|---|
| 首页主标题 | 36/44px | 700 | 手机收至 28/36，不截断主价值表达 |
| 页面标题 | 28/36px | 650–700 | 不挤占工作区 |
| 内容/作品标题 | 20/28px | 600–700 | 文档正文内层级独立 |
| 面板标题 | 16/24px | 600 | 来源、版本、检查 |
| 正文/按钮 | 14/22px | 400/500–600 | 继承现有主体字号 |
| 辅助信息 | 12/20px | 400–500 | 以可读性优先，不承担主要操作信息 |
| 紧凑控件 | 13px | 500 | 本轮补充尺度，记录为新增 |

作品缩略图可缩放其内部画面；不能把缩略图小字用于真实表单关键提示。原型中的图表与时间均为模拟，不代表商业数据。代码不向 UI 暴露 chain-of-thought。

## 4. 间距、圆角与阴影

基础间距4px，常用4/8/12/16/20/24/32/40/48。原始源已有4/8/16/24/48；12/20/32/40是本轮布局补充，不冒充原源中已存在。

圆角：控件6、卡片8、弹窗10、大容器12、标签pill999px。避免每个面板自定义不同圆角。卡片常态极轻投影，hover 只增加轻浮起；工作台大分区靠描边，不靠厚重投影。

| 组件 | 内边距 | 间距 | 尺寸 |
|---|---|---|---|
| 导航项 | 10px 12px | 图标文字10px | 40px目标行高 |
| 正常按钮 | 8px 14px | 图标8px | 桌面36px，移动主动作44px目标 |
| 小按钮 | 6px 10px | 6px | 30–32px |
| 创建器 | 16–20px | 区块16px | 大输入 min-height 116px |
| 作品卡 | 16px | 12px | 缩略图统一高度、标题单行省略 |
| 对话消息 | 16px | 段落8–12px | 对话列自滚动 |
| Drawer | 24px | 条目16px | 460px，手机100vw |

## 5. 响应式规格

| 宽度 | 导航 | 工作台 | 主要行为 |
|---|---|---|---|
| ≥1280px | 224px完整侧栏 | 对话388px + 作品余宽 | 对话和预览独立滚动 |
| 1024–1279px | 可收至紧凑侧栏 | 对话列压缩但至少320px | 顶部次要文案可隐藏 |
| 760–1023px | 紧凑/折叠导航 | 保留双栏到可用阈值 | 表格仅局部横滚，页面不横滚 |
| <760px | 抽屉导航 | 对话/作品/来源切换 | Composer留在对话视图、Drawer全宽 |

原型断点的实际行为以 `prototype/app.css` 为准；本表是目标约束。验收1440、1280、1024、768、390px，并至少一个更大系统字号环境。移动端不是硬压缩桌面；来源和版本通过独立浮层打开。

## 6. 组件规格与状态

| 组件 | 状态 | 键盘/焦点 | 业务约束 |
|---|---|---|---|
| Brand/导航 | 默认、hover、active | Tab，链接可回退 | 使用真实现有 Logo 资产，原型层叠图标只是有授权的库图标 |
| TypePicker | 可用、选中、不可用 | 按钮或radio语义，选中可读 | 无能力时注明原因 |
| Composer | 空、草稿、上传中、可发、忙、只读、重连 | Enter发送，Shift+Enter换行；IME组合不误发 | 不丢附件/知识/base version |
| RunSummary | 排队、执行、等待、取消中、不明、终态 | details可展开 | 不显示主模型内部推理 |
| ArtifactPreview | 无版本、取票中、有效、过期、拒绝、检查失败 | 给iframe标题，焦点返回 | 换版销毁旧预览环境 |
| VersionRow | 选中查看、编辑基线、不可恢复 | 独立查看/恢复按钮 | 不以选中代替恢复 |
| SourceRow | 引用、待用、索引中、撤权 | 可打开原文的控件明确命名 | 无权不读原文缓存 |
| DecisionCard | 等待、提交中、已记录、送达不明、已确认、过期 | 具体操作名，不只“确定” | 允许一次，不默认永久权限 |
| Notice | 重连、失败、取消、只读、过期、不明 | aria-live适度播报 | 不以红色把断线当失败 |
| Dialog/Drawer | 开/关/提交中 | native/Radix焦点约束，Escape，关闭后返回 | 破坏操作不可点遮罩隐式提交 |
| Export | 无交付、可下载、无权、到期 | 下载按钮有版本信息 | 明确下载当前查看版本 |

生产优先复用 `@weknora/ui` 中已有 primitive 与状态行为。assistant-ui 负责对话 primitives；自定义工具卡、审批卡通过适配槽呈现。原型用原生 HTML/JS 表达视觉和行为，不携带 assistant-ui npm 依赖。

## 8. 视觉回归要求

每一生产组件至少固定默认、hover/focus、disabled、loading/error中适用状态的截图。验证页面结构、对比度、长标题、中文/英文混排、文件名过长、滚动和弹窗。基准截图必须用同宽度与同状态比较；不同作品的画布内容不算 UI 回归。

本包截图来自离线内嵌 HTML 的 Chromium 渲染；运行方式、实际检查结果和未覆盖事项见 `qa/验证报告.md`。完整 App 路由、真实字体、现有共享组件实际视觉、用户浏览器 `file://` 行为都须在实施阶段再验。
