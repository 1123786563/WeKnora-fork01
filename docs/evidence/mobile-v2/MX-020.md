## 交付（三域交互互斥——D-012 矩阵消费）

- **BudgetApproval.tsx**：旧上限/新申请/差额三值展示（读屏完整句）；`canAuthorize` 分权（无权限=文案导向有权限成员+无按钮——budget_authorize 角色校验位）；批准语义=「仅提升上限，不直接执行任务」（extend）。
- **QuestionForm.tsx**：服务端 options 优先渲染（选项按钮直提）；自由文本长度校验（maxLength 超限禁提+错误双通道）；**提交用户编辑后的最新文本**（问题切换清空防残留）；helper 计数；recovery 语义朗读。
- **ConnectionConsent.tsx**：五态（idle/authorizing/connected/failed/revoked）；授权经**受信系统浏览器**（App 不内嵌 Provider 凭据输入）；authorizing 态=等待回跳+查询状态按钮（状态由产品 API 查询驱动，非客户端假设）；授权范围明示。
- 挂载 spec：三组件真实渲染断言——**工具审批卡零预算字段**（互斥验证）、编辑后提交最新文本、authorizing 展示；预算三值+分权门控。
