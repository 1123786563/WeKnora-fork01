## 交付

- **voice/dictation.ts**：`createDictationStateMachine`（纯状态机，真实语音引擎经事件注入——不模拟识别）——
  - transcript 进入**未发送草稿**；用户编辑（user_edit）后草稿停止跟随识别（保护修改）；
  - 确认=submitVia（会话草稿通道）提交**编辑后的最新文本**（frozen）；确认后听写草稿清空；
  - 取消听写=丢弃本段（不影响已确认）；与停止听写、取消任务三动作分离（状态机只有前两者，任务取消在 UI 层独立按钮）。
- **VoiceInputScreen（M16）**：听写状态 badge；草稿框（读屏完整句）；开始/结束听写；确认并放入会话草稿（文案明确「以你编辑后的最终文本」）；取消听写（丢弃本段）；取消任务独立 danger 按钮（文案明示「与取消听写是不同操作」）；确认计数提示「进入会话草稿，未直接发送」。
