## 交付

- **resources/artifact-viewer.ts**：`createArtifactViewer`——
  - `open` **每次重新授权**（无授权缓存复用）；authorized→会话内（仅内存）短期签名；expired→清本地引用返回 expired（重授权重开=再调 open）；revoked/not_found→清一切本地引用；
  - `persistentSignedUrls()` **结构性返回空**（无持久化通道——签名 URL 不落盘）；
  - `share`：确认外流范围才计数分享（未确认=零分享）；分享语义携带不可变版本与来源 run 说明；
  - `clearSessionCache`：页面离开/切空间时清理（ArtifactScreen unmount 调用）。
- **resources/share.ts**：系统分享边界——只携带标题+版本说明（签名 URL 不外流）；rn-mock 补 Share/Image 基底。
- **ArtifactScreen（M14）**：版本卡（v{n} 不可变版本+来源任务+读屏）；五相（loading/ready/expired/revoked/not_found/error）——expired 态明示「短时签名授权，点击重新授权」；revoked 态清内容+联系管理员；图片=原生 Image 渲染签名 URL（单次）；文本/表格=安全原生渲染说明（动态 HTML 静态化策略）；有效期可见；分享经确认 Sheet（明示不含访问链接）；unmount 清缓存。
