## 交付（关闭 G06）

- **execution-storage.ts**：
  - `ExpoSQLiteDatabase` 接口对齐**官方** expo-sqlite API——`withTransactionAsync(work: () => Promise<void>): Promise<void>`（不再伪造泛型返回）；
  - driver `transaction<T>` 经闭包捕获工作结果（官方 API 不回传事务结果）；失败异常自然上抛回滚；
  - 新增 `readCursor(runID)`（恢复编排依赖）。
- **native-host.ts（新，组合根）**：真实 `expo-sqlite openDatabaseSync` → 官方绑定值类型适配；真实 SecureStore AEAD 密钥（**single-flight**：并发首次加密共享一次初始化）+ libsodium XChaCha20-Poly1305（复用 app 既有 libsodium.lib）；`openNativeExecutionStorage(scope)` 返回存储句柄（含 closeSync）。依赖 `expo-sqlite ~55.0.20`（官方 SDK55 矩阵，经 package.json 锁转移登记）。
- **recovery.ts（新）**：`planRecovery`（本地有底→resume-from-cursor；无底→snapshot-first）；`hydrateFromSnapshot`（快照事件按 seq 幂等提交后 cursor 停 watermark；cursor_expired 同路径重建，不重启 Run）。
- **execution-cache.ts（domain）**：`hydrate(runID, events)`——升序幂等水合（重复 seq 跳过、缺口抛错），供快照→内存投影。
