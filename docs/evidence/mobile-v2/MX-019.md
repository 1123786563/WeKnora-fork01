## 交付

- **interactions/controller.ts**：`createInteractionController`——
  - `openConfirmation` 强制刷新当前详情（禁止陈旧缓存直接确认）；
  - `confirm` 陈旧守卫：快照 revision/args_hash 与最新事实不一致 → **零发送 + refresh**（409 语义前置化，客户端绝不重发旧决定）；generation 失效（切空间）同判；已决定记录幂等（acknowledged 不重发）；kind×action 矩阵外拒绝；
