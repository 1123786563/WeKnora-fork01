## 验证架构（native-component 层）

RN 本体含 Flow 语法，node 环境不可直接加载（实测记录）。采用**模块边界基底 mock**：
- 产品组件为真实实现（消费 theme.ts 令牌，无散落常量）；
- `vitest.mobile-v2.config.ts` 专用配置将 `react-native` 别名到 `tests/mobile-v2/rn-mock.tsx`（最小可挂载原语 + 可观测 AccessibilityInfo/BackHandler/findNodeHandle）；
- 真实 `react-test-renderer` 挂载；frozen 场景在 spec 内运行并输出 `MX008-OBSERVATION` 结构化行；
- tsx probe（frozen 命令链）execFile 该 vitest 套件并解析观测——与 Go probe 同一模式。
- 明确边界：此为 **native-component 层证据**（真实组件逻辑+挂载），不替代设备链路（MX-034 native-e2e）；默认 vitest 全量入口不受影响。

## 组件清单（全部消费令牌主题）

- **Button**：primary/secondary/danger × disabled/loading；minHeight 48/44（不固定高度，大字体不裁切）；busy 不重复触发（loading/disabled 抑制 onPress，spec 断言 dispatched=0）；danger 有图标位且 label 语义来自调用方（不只靠颜色）；focus 态 focus 色边框；accessibilityRole/Label/State 齐备。
- **Card**：surface/alt/hero 三调、compact 间距、可点击时整卡单一点击区（无嵌套点击）。
- **StatusBadge**：六 tone（soft 底+深字）——文字与颜色同时存在。
- **StateView**：loading/empty/error/offline/noPermission/capability 六态 props 驱动；动态文案拼接完整句子供读屏（accessibilityLabel）；error 态 assertive live region；动作位由调用方接真实命令。
- **Sheet**：关闭≠决定（onClose 只收起；决定只经 footer 显式按钮）；遮罩/Android 返回键关闭；打开焦点到标题、关闭焦点回归触发元素（AccessibilityInfo.setAccessibilityFocus + findNodeHandle）；ScrollView+maxHeight 大字体；内容区不可整体点击。
- **Field**：label/value/helper/error；错误状态并入读屏 label 与视觉颜色双通道；不固定输入高度。

## RED 记录

- 首跑挂载套件失败两次（真实断言链路）：①spec 相对路径深度错误（模块找不到）；②类型修复轮（TextInput accessibilityState 不在 RN 重载、mock 小写 JSX 标签不在 IntrinsicElements、react-test-renderer 无声明）——typecheck 一度 14→23，全部修复后回到 **14=基线**。
- frozen 场景从未被“直接写绿”：观测值来自真实挂载行为（决策计数器在组件 onPress 回调内、焦点记录在 mock AccessibilityInfo 内）。
