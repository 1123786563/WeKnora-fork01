- **bootstrap.ts（新）**：`resolveScopeFromMe`（纯解析：user.id 必填；memberships 行容错解析 tenant_id 数字/字符串；空间选择优先级=调用方记忆>服务端当前 tenant>首个 active 成员关系）+ `createBootstrapPort`（真实 `GET /api/v1/auth/me`，A 类端点）+ `createTransportBootstrap`。失败上抛——保留凭据、不臆造 scope。
- **session.tsx（改）**：冷启动凭据恢复后，scope 未定（userId/tenantId 均空）即经真实 /auth/me 补齐 user/membership 再 `scope.switchTo`（G04：恢复凭据≠恢复身份）；`replaceCredential`（SSO 换取路径）同样接 bootstrap；新增 `bootstrapScope`/`bootstrapError` 到 context（UI 可触发重试/展示错误，不静默吞错）。bootstrap 请求携带当前 bearer（经注入 store 读取，不落普通存储）。
- **screens/LoginScreen.tsx（新，M01）**：令牌组件视觉（Field/Button×2/StateView）；密码登录走 useProductAuth().login（真实 /auth/login）；SSO 走 createOIDCApi.startNative（真实签名 (redirectURI, challenge)，PKCE verifier/state 落 SecureStore）；错误态文字+颜色双通道；onAuthenticated 回调解耦宿主（入口接线归 MX-013，D-023）。
