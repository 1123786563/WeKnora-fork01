# open-connector 使用共享运行时，由 WeKnora 管理租户隔离

WeKnora 需要在多租户 SaaS 中提供多服务连接和操作能力。用户于 2026-09-12 明确选择“共享运行时，WeKnora 管理租户隔离”：首期在私网共享 open-connector，由 WeKnora 校验连接归属，并使用按连接限制的运行 Token。相比每空间独立运行时，该方案减少实例和升级成本；相比按客户等级混合部署，首期运维与路由更简单。

共享运行时不构成数据库级或进程级租户隔离；管理凭据失陷会影响同一运行时中的多个空间。终端用户和 Agent 不得直接获得运行时管理权限。保留未来独立实例选项，但本次选择不要求实现自动实例编排。

本 ADR 仅确认部署与租户隔离方向，不代表 OAuth 桥接、数据模型、实施任务或运行验收已获批准或完成。具体建议与验收门槛见 [集成设计稿](../superpowers/specs/2026-09-12-open-connector-integration-design.md)。
