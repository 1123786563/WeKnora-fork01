# Paseo 移动端接入 WeKnora 可信云

移动端以 Paseo 为目标底座，借鉴 Happy 交互及同步、多设备设计；当前 Flutter `apps/mobile` 不作为目标底座。首版链路为 Paseo mobile → WeKnora Workbench/Run → WeKnora 云沙箱，不采用 Paseo daemon。WeKnora 是唯一后端，所有任务及文件、Git、终端操作均在可信云端执行，并按空间（Tenant）归属、授权与隔离。

云端可读取任务已授权内容，传输和存储加密；不承诺 Happy 式云端不可读 E2EE。首版范围为空间切换、Agent 会话、云端任务、审批、文件与产物、知识资源，管理配置随后补齐。iOS 与 Android 是首版验收目标；Paseo Web 保持可构建，完整 Web 仍由现有 WeKnora 提供。

一个任务对应一个持续会话，可包含多次运行；继续和重试保留上下文。运行可持续执行、持久等待审批或在副作用结果未知时保持阻断；完成、失败和待审批会推送，锁屏通知不含标题和正文。离线仅缓存可读内容与草稿，缓存按账号和空间隔离加密，退出清理；联网发现撤权后清缓存，离线无法立即撤权，用户可关闭缓存。

任务默认仅创建者可见，可显式共享给空间成员。共享成员只能只读查看对话、运行及获准文件/产物，不能继续执行、使用终端或代创建者审批；既有后端审批权限仍为权威。工作文件跟随任务权限，发布产物和知识资源按目标权限控制。

任务使用独立持久工作区，同一任务的多次运行复用；不同任务默认不共享可写目录，须显式导入复用。任务结束后文件保留，计算可休眠并在续用时恢复；空间存储配额超限时限制新增写入，仍允许查看、导出和清理，首版不按天自动删除任务文件。

用户选择固定版本发布时，原任务保持私有，发布副本仅可指向当前空间产物资源或指定知识库并按目标权限可见；修改后须重新发布，不自动覆盖，撤销任务共享不撤销已发布副本。首版不跨空间发布或提供公开互联网链接，仍可下载和导出。

活跃 Run 的终端只观察输出；交互 PTY 或人工编辑先停止 Run 并确认停止，结果未知时保持阻断。任务 Owner 使用个人代码平台 Connection，clone 前检查授权；在云工作区克隆、修改、查看 Diff 与创建本地 Git 提交不额外审批。每次 push 分支或创建 PR 展示 repo、branch、具体变更并审批，代码平台负责合并；只读共享成员不得使用凭据。凭据由 WeKnora 管理，不进入聊天产物，且不提供 force push 或远端删除分支入口。

本 ADR 已收口产品决策；缓存容量、淘汰与恢复为工程参数，相关能力仍须实施并取得真实验证。
