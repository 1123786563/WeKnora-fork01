## 阅读顺序

1. `00-源码核查.md`：真实仓库结构、已实现能力、缺口与改造风险。
2. `01-Taro微信小程序技术方案.md`：架构、共享边界、身份、流、任务、知识、支付、接口增量及分期任务。
3. `02-页面与交互说明.md`：20页字段、布局、按钮、异常、权限与接口对照。
4. `wireframes.html`：总入口，全部HTML/CSS/JS内联；下载后用浏览器打开，不需要安装依赖。
5. `03-验证与限制.md`：已执行的原型验证及未验证事项。

`wireframes/index.html` 是同样的总入口。`wireframes/pages` 提供20个独立HTML入口，每个默认打开对应页面；均内置完整导航逻辑，方便单独交付评审。宽屏显示页面列表、手机模拟器和设计说明；窄屏只显示手机页面。

`previews/overview.png` 是6个核心页面总览；`previews/studio.png` 是桌面评审界面；其余PNG为各页截图。`source-manifest.json` 给出固定版本源码链接与选读范围。`audit` 为SSE分块风险的独立最小复现。

## 推荐体验路径

登录 → 选择工作空间 → 工作台 → Agent → 发起任务 → 执行详情 → 审批 → 产物。

知识库 → 库详情 → 添加文件/URL → 解析状态 → 引用文档 → 对话。

我的 → 用量与套餐 → 报价与支付 → 打开“演示通道可用”开关 → 支付待确认 → 模拟后端付款/履约确认。

所有账号、价格、余额、任务、文档和交易均为示例；原型不调用微信或真实后端。并非可提交微信审核的生产小程序。未修改或推送原仓库，未包含完整源码克隆或任何字体文件。
