## Ruling（实现期裁决）

1. **服务返回类型**：计划 Produces 写 `(*dto.PluginMyConnection, error)`，
   但 interfaces 包不得依赖 handler 层（既有注释与 OCR F2 惯例）——改为
   types 层 `types.PluginMyConnection`，handler 映射到 `dto.PluginMyConnection`
   （与 PreviewResult/InstallationResult 同构）。若错，代价是 DTO 双形状
   维护，可低成本收敛。
2. **过期+有 refresh 的三态归属**：计划只定义"过期且无 refresh→expired"。
   本实现把"过期但有 refresh"归入 authorized（运行时 ensureFresh 以既有
   同意自动续期，成员无需重授权），fake 测试 c2 钉死该映射。若产品语义
   想要单独态，代价是枚举扩容+前端适配（T12 消费 State 字符串）。
3. **plugintest/server.go 由本任务创建**：Brief 写 Modify 但 T10（Create
   所有者）在本会话开始时未实施且无进行中迹象（目录不存在、无 T10 执行
   记录、git status 无其未跟踪文件）。按 T10 brief 规格实现基线 API
   （Start/SetTools/Calls/WriteCalls/Manifest）+ 本任务 EnableOAuth，T10
   的测试文件（server_test.go/plugin_agent_integration_test.go）未动。若
   T10 并行会话已启动将产生同文件冲突——orchestrator 合并时需二选一。
